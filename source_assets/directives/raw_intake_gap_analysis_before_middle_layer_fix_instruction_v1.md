# CODEx directive - raw intake gap analysis before middle-layer fix v1

## purpose
- compare three paths before any middle-layer patch:
  - structured document path
  - external case intake path
  - engine-only raw intake path
- derive middle-layer requirements from records, not intuition
- keep current/shared reality/core untouched

## required outputs
- one comparison report
- one middle-layer requirement note
- one verification plan

## do not do
- do not patch promotion logic
- do not patch inputter/labeler yet
- do not expand current asset map
- do not rewrite shared reality or baseline docs

## one-line lock
- compare first, infer middle-layer requirements second, patch later.
