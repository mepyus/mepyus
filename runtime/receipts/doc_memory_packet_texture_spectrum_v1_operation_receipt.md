## 3. key judgment

- packet 질감은 우열표가 아니라 비교 기억용 생육 상태다.
- `overcompressed`, `breathing`, `closure-heavy`, `structured-open but low-emergence`, `dialogue-supportive` 같은 언어로 자산을 읽는 것이 현재 구조에 더 맞다.
- packet 질감 문제와 2차 scaffold carryover 문제는 분리해서 읽어야 한다.
