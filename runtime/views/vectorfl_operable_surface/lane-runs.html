왜 lane 비교를 따로 보는가

human-first
이 페이지는 여러 실행 결과를 병렬로 자랑하는 곳이 아니라, 같은 line과 같은 pipeline에서 무엇이 달라졌는지 비교해 지금 어떤 실행 경로를 채택하거나 보류해야 하는지 판단하는 비교면입니다.
지금 무엇을 하는 중인가
현재 case semi_live:choi_ai_classroom_vlm에서 # raw intake gap analysis before middle-layer fix을 중심으로 읽기, 실행, 귀속을 묶는 중입니다.
