## Do
- **Program Frame Setup**: 프로그램 단위 선언을 명문화하고, 현재 '닫힌 경계(Closed Boundary)'를 명시한다.
- **External Pattern Map**: 외부 도구별 [Codex workflow 레이어 / memory-mission 분리 / gateway 개념]을 VectorFL의 4개 층위(Container, View, Styles, Service) 또는 파이프라인 요소와 연결하여 구조화한다.
- **Handoff 작성**: Session 2에서 공간 기록을 활성화하기 위해 필요한 라인/축/카메라/렌즈 후보를 간략히 정리한다.

## Do Not

- 외부 도구의 구조를 통째로 복제하지 말 것.
- "최종(final)", "배포 준비(ready)" 등 단정적 언어를 사용하지 말 것.
