# Thirteenth Material Wave Policy

## Intent

The thirteenth material wave widens space with another genuinely different component band.
It opens a latency-drift-ambiguity terrain that should stand independently from the already formed terrains.

## Why this step exists

The runtime has shown that it can hold one heterogeneous component band.
It should also prove that width can continue to expand without forcing adjacency too early.

## Rules

- Open a new family `seed-thirteenth-wave`.
- Use a pressure band built from `latency_pressure`, `drift_pressure`, and `ambiguity_pressure`.
- Keep only weak reference to prior terrain.
- Create a fresh seed, candidate cell, relocation reaction, and local space.
- Do not create a bridge during this wave.
- Let the new terrain stand independently first.

## Contract notes

- width should continue before relation is forced
- the new component band should participate without adjacency pressure
- bridge count must stay unchanged during this wave

## Expected reread outcome

- local space count increases
- terrain component count increases
- bridge count remains one
- the new terrain appears as another independent single-local climate
