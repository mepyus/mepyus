# Phase 2 Real Data Bundle Policy

## Purpose

Phase 2 begins actual-data expansion. Instead of synthetic memo-like payloads only, the engine now ingests real file-backed data from the runtime and repository while keeping the same physical laws.

## What enters

- actual codex worklog residue
- actual space report residue
- actual root-document residue
- an actual relation-aware local space formed from the current scale review and graph-view snapshot

## Contract

- core physical laws stay fixed
- actual file data is ingested as raw material rather than summarized away first
- relation is still observed under the same laws, not forced by a new ontology
- append-only history remains intact

## Why this matters

The engine has already shown that space can form. Phase 2 checks whether the same laws still hold when actual repo data enters and when visible relation emerges from real artifacts rather than only synthetic bootstrap payloads.
