# vectorfl Failure Patterns

`../vectorfl`를 frozen reference로 읽으면서 경계로 삼아야 할 실패 패턴을 적는다.

## Pattern 1. Stage gravity

stage 흐름이 강해질수록 중간 형성 단계를 살아 있는 구조로 보기보다 다음 단계 입력으로만 보게 된다.

## Pattern 2. Premature point thinking

candidate나 seed를 이미 point 전단계로 보고 압축해 버리면 이후 공간 형성 다양성이 줄어든다.

## Pattern 3. Cluster relapse

공간을 cell이 아니라 cluster 언어로 읽기 시작하면 `space_cell`의 의미가 사라진다.

## Pattern 4. Reader bleed

observer나 reader vocabulary가 core schema로 들어오면 계약 위반이자 회귀 신호다.

## Pattern 5. Metadata substitution

시간, 감정, 환류를 실제 경로 변화 대신 필드 몇 개로 대체하면 압력 수용성이 죽는다.

## Pattern 6. Bridge overreach

bridge를 relation trace가 아니라 merge lane으로 다루기 시작하면 multi-local-space openness가 줄어든다.
