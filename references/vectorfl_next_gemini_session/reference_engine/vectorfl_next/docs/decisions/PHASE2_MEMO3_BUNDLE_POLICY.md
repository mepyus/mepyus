# Phase 2 Memo3 Bundle Policy

## Purpose

Bring `memo3.md` into the runtime as actual memo material without changing the existing physical laws, then observe whether it forms:

- an independent file-backed local space
- a relation-aware local space with earlier memo bundles

## Contract

- `memo3.md` enters as raw memo material first
- no new ontology is introduced for memo content
- bridge growth is not forced
- relation is observed only through the same `material -> trace -> point_seed -> space_cell -> local_space` path

## Why this matters

Phase 2 now needs actual memo progression, not only synthetic widening. `memo3.md` carries runtime, view, extraction, and snapshot concerns that should be visible in the same space-first graph without changing the physics.
