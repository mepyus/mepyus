# First Scale Review Policy

## Purpose

The first scale review is a descriptive pass over the current widened runtime. It does not introduce new core states, new ontology, or pass/fail gates. It rereads the current field through the five agreed review axes:

- quiet persistence
- multi-speed coexistence
- reflux effect
- perspective invariance
- non-purpose survival

## Contract

- the review is descriptive only
- it must not replace append-only history
- it must not force closure on sparse or weakly legible presence
- it must not reinterpret bridge growth as the primary sign of scale
- it must help judge whether the same physical rules still hold as the field widens

## Why this matters

First-scale expansion is no longer a tiny bootstrap. The engine now needs a recurring review pass that checks whether wider space still preserves quiet presence, varied formation speeds, reflux material, observer consistency, and non-purpose survival.
