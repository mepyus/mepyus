# md_maker Index

## 목적

이 폴더는 `WashTank`를 바로 수정하기 위한 코드 폴더가 아니라,
`WashTank`를 다시 읽고, 그 과정과 의도를 md로 복원하기 위한 기록 폴더다.

즉 이 인덱스는

- 어떤 문서가 이미 만들어졌는지
- 각 문서가 무엇을 설명하는지
- 어떤 순서로 읽으면 좋은지

를 정리하기 위한 시작점이다.

## 현재 문서 목록

### 0. reader_guide.md

역할:
- `md_maker` 전체를 어떤 관점과 순서로 읽으면 좋은지 안내하는 상위 가이드
- 개요형 / 엔진형 / 과정형 읽기 경로 제시

언제 읽는가:
- 처음 이 폴더에 들어왔을 때
- 어떤 문서부터 읽어야 할지 정하고 싶을 때

### 1. WashTank_overview.md

역할:
- `WashTank` 전체를 개요 수준에서 다시 읽는 문서
- 왜 이런 프로그램이 되었는지
- 왜 화면이 공정 / 역할 / 부지 단위로 나뉘었는지 정리

언제 읽는가:
- 처음 전체 맥락을 잡을 때

### 2. WashTank_process_flow.md

역할:
- 입고, 세척, 검사, 수리, 셔틀, 출고까지 이어지는 공정 흐름 정리
- 탱크가 어떤 단계들을 통과하도록 상상되었는지 복원

언제 읽는가:
- 화면보다 먼저 전체 흐름을 보고 싶을 때

### 3. WashTank_screen_roles.md

역할:
- 각 JSX 화면을 역할 기준으로 다시 배치
- 사무실 / 현장 / 장비기사 / 보드 계열로 정리

언제 읽는가:
- 파일별 의미와 자리 잡기를 확인할 때

### 4. WashTank_engine_and_data.md

역할:
- `JMS`, `DB`, `상태 전이`, `이벤트`, `위치` 관점으로 구조 읽기
- 이 프로그램이 단순 UI 모음이 아니라 상태 전이 엔진 소비자라는 점 정리

언제 읽는가:
- 엔진 관점과 데이터 구조를 이해하려 할 때

### 5. WashTank_build_traces.md

역할:
- `WashTank`를 완성품보다 과정 흔적이 남은 폴더로 읽는 문서
- 어떤 실험과 분화가 있었는지 기록

언제 읽는가:
- "이 프로그램이 어떤 과정으로 이렇게 되었는가"를 보려 할 때

## 이 폴더를 어떻게 쓸 것인가

이 폴더는 단순 요약 폴더가 아니다.

앞으로는 아래 같은 문서가 더 들어올 수 있다.

- 파일별 메모 문서
- 특정 공정 집중 문서
- `JMS` 상세 메모
- `db.md`, `tms.md` 재해석 문서
- 화면 간 관계 문서
- `WashTank`를 만든 과정의 연대기 문서
- 화면 생성 이유 심화 문서
- JMS와 화면 연결 상세 문서
- 용어집 / 사전 문서

즉 이 폴더는 `WashTank`를 다시 이해하기 위한
md 기반 해설 레이어로 계속 자라날 수 있다.

## 한 줄 정리

이 `md_maker` 폴더는 `WashTank` 코드를 설명하는 곳이 아니라,
`WashTank`가 어떤 생각과 흐름으로 만들어졌는지를 다시 읽기 위한 기록 레이어다.
