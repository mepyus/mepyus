솔트룩스 이경일 대표 강연 정리
"공공 AX(AI 전환)와 에이전틱 AI — 온톨로지로 완성되다"

1. AI 역사와 현재 흐름
1950년대 퍼셉트론·폰노이만 컴퓨터에서 출발한 AI는 두 번의 윈터(침체기)를 거쳐 현재 세 단계로 진화 중입니다.

생성 AI → 에이전틱 AI (현재) → 피지컬 AI (미래)

특히 테스트 타임 스케일링이 핵심 변화입니다. 질문에 즉각 답하는 것이 아니라, AI가 기획 → 고민 → 검토 → 전략 수립의 과정을 거쳐 목표에 도달하는 방식으로 진화했습니다.

2. 루시아(Luxia) — 솔트룩스의 자체 LLM

루시아 3 → 3.5까지 출시, 개발 누적 투자 약 600억 원
큐원(중국), 라마, 미스트랄, 젬마 등 글로벌 모델과 비교해도 경쟁력 확보
핵심 기능: 적응형 추론(Adaptive CoT) — 쉬운 질문은 빠르게, 복잡한 질문은 깊게 사고
온프레미스 설치 가능 → 국방·공공·보안 분야에 적용 가능한 유일한 국내 모델


3. 에이전틱 AI란?

"스스로 생각하고 행동해서 목표에 도달하는 수학으로 만들어진 데이터 덩어리"

기존 AI vs 에이전틱 AI 비교
구분방식챗GPT프롬프트 → 즉각 답변RAG프롬프트 → 검색 → 답변에이전틱 AI추론 → 계획 → 반복 조사 → 검증 → 최종 답변
구버(Goover) 딥리서치 작동 과정 예시

질문 입력 → 벡터 공간 검색(~100개) → 문서 정독 → 부족한 부분 재질문 → 16~38개 문서 선별 → 추론 → 목차 및 답변 플래닝 → 최종 리포트/팟캐스트/PPT 생성

할루시네이션이 거의 제로 수준으로 감소합니다.

4. 왜 온톨로지인가?
LLM의 근본적 한계:

벡터 임베딩(2,000~3,000차원)으로는 숫자·정형 데이터를 정밀하게 표현 불가
확률 통계적 생성 방식 → 수치 데이터 오류 불가피

온톨로지의 역할:

아리스토텔레스의 프레디케이트 로직(2,400년 전)에서 출발한 의미적 지식 그래프
숫자·정형 데이터를 컨텍스트를 가진 의미 데이터로 변환
Knowledge Grounding 적용 시 수치 관련 할루시네이션 제로
CPU로 구동 → GPU 비용 대폭 절감

성능 비교 (도메인 질의 기준)
방식도메인 정확도일반 LLM51%어드밴스드 RAG78~82%온톨로지 + 딥서치 + LLM대폭 향상

5. 팔란티어 방식 — 데이터 패브릭
팔란티어 성공의 핵심은 데이터를 하나로 통합하지 않는 것입니다.

❌ 기존 빅데이터: 모든 데이터를 하나의 웨어하우스로 통합 → 대부분 실패
✅ 팔란티어: 각 데이터 사일로를 유지하면서 온톨로지로 의미적 통합 (데이터 패브릭/매시업)


예: 미국 국방부의 위성·드론·항공모함·IoT 센서 데이터를 물리적으로 합치지 않고, 온톨로지 스니펫만 추출해 통합 후 추론엔진 구동

솔트룩스는 2025년 5월 SAC(솔트룩스 AI 컨퍼런스)에서 자체 온톨로지 파운드리 출시 예정입니다.

6. 공공 분야 적용 사례

서울 교통서 국민안전 GPT — 안전 법령 학습, 매뉴얼 없는 사고 상황 대응
원전 형상 관리 시스템 — 수만 가지 부품·법령 변경 사항 자동 관리
국립재난안전연구원 DIGPT — 기상·재난 정형 데이터 + 온톨로지 결합, 정확한 재난 분석
연세의료원 등 4개 병원 — 병원 AI 자동화 서비스


7. 실무 적용 핵심 조언 4가지

문제 정의 먼저 — 플랫폼·기술보다 "우리가 해결할 문제가 무엇인가"부터
멀티모델 체계 구축 — LLM 하나가 아닌 여러 모델을 라우팅·협업시키는 구조
MCP/A2A 도입 — 각 데이터 소스와 도구의 자율 운영을 위한 표준 프로토콜
패스트 프로토타이핑 — ISP 6개월 대신 4~8주 안에 실제 작동하는 시스템 구축 후 검증·확대


8. 대한민국의 미래와 소버린 AI
인구 위기: 23년 후 전체 인구의 50% 이상이 65세 이상, 노동 인구는 현재의 절반으로 감소 → 공공 서비스 지속 가능성 위기
미국 AI 패권 전략: 백악관 AI 액션 플랜 = "너희들 AI 만들지 말고 우리 우산 밑으로 들어와" → 초지능 제국주의

소버린 AI의 본질은 LLM 기술 자체가 아니라, 우리의 업무 프로세스와 지식을 AI로 자율화하고 운영할 수 있는 능력입니다. 현대자동차·삼성전자의 핵심 경쟁력이 장비가 아닌 내부 프로세스 노하우인 것처럼.



한 줄 요약: LLM + 온톨로지 + 에이전틱 AI의 결합이 공공 분야 업무 혁신의 핵심이며, 기술 도입보다 문제 정의와 빠른 실증이 먼저다.
