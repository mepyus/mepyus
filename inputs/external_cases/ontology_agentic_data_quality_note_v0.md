## why this source matters

This source matters because it argues that agentic systems need structured and curated data foundations, not just more agent loops.

It overlaps with our current space around:

- hallucination limits
- structured data or schema pressure
- data quality before downstream agent use
- active maintenance of relations rather than static storage

## core claim

The source argues that an agent ecosystem built on LLMs alone remains unstable because hallucination and poor data quality remain unresolved.

Its proposed answer is not "more prompting" but stronger structured data organization:

- ontology
- relation structure
- cleaned and usable data
- active maintenance rather than static classification

## structural pattern

The source emphasizes several ideas:

### 1. agents need curated foundations

Agent outputs are only as reliable as the quality and structure of the data underneath them.

### 2. ontology is dynamic, not static

The source pushes toward an active ontology model where entities, relations, and updates remain live instead of frozen.

### 3. data quality is a bottleneck

Even a strong structural model fails if:

- source data is incomplete
- authority or reference quality is weak
- public data looks complete but is actually thin or broken

### 4. structure can reduce downstream burden

If the data layer is better organized, downstream search, response, and cost pressure can drop.
