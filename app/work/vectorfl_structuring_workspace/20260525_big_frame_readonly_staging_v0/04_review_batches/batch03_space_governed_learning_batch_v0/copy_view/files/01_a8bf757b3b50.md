## 4. Cross-source Common Signals

### 4.1 Context / Resource Containment

Sources involved:

```text
context-mode
GoModel
prior MCP lens
```

Synthesis:

```text
The space needs a clear separation between raw context, trace/resource material, and bounded evidence returned to reasoning.
Workers should not flood the main reasoning surface with raw execution output.
Trace/resource material can support re-entry and bounded retrieval, but it must not become authority.
```

Preserve:

```text
output containment
session guide / re-entry support
intent-based filtering
trace / observability reference
```

Boundary:

```text
trace/resource material is not registry, ledger, truth source, or current-position update.
compression and filtering must not hide important judgment evidence.
```

```text

Instead, build a space that can separate context from action,
plan from execution,
evidence from authority,
and strategy from implementation.
```

Project direction:

```text
The project should remain model/tool-agnostic by strengthening its internal process grammar.
```

User-facing reading:

```text

GoModel shows why execution/provider surfaces need observability and User-visible boundaries.
AI Frontier EP94 shows why fast model/tool change makes User judgment and internal process grammar more important.
```
