# Gemini Worklist - Line-to-Axis Formation Process Asset Dry Run v0

## 0. Mode

This is a bounded dry run of line-to-axis formation reading.

Do not implement anything.
Do not create automation.
Do not create runtime scripts.
Do not create registry, index, ledger, router, controller, formal schema, official workflow, or ontology.
Do not update current-position.
Do not promote any line or axis to baseline.
Do not attach any tool/API/function/repo.
Do not read new external sources.
Do not broad-crawl `docs/reports`.
Do not treat Gemini output as verified truth or final authority.

Your output is worker evidence only.

The purpose is not to prevent axes.

The purpose is to test whether lower-level process assets produce connection seeds, line candidates, and possible axis candidates.

## 1. Core Frame

Use this rule:

```text
Axes are not blocked.
Premature axis fixation is blocked.
Evidence-bounded axis formation is encouraged.
```

Read through this formation path:

```text
MATERIAL
-> CONNECTION_SEED
-> LINE_CANDIDATE
-> LINE_CONFIRMED
-> AXIS_CANDIDATE
-> ORIENTATION_AXIS
-> REUSABLE_READING_AXIS
```

Keep `WATCH / HOLD` available when evidence is thin or overhardening risk is high.
