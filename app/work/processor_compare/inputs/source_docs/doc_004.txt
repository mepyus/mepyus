Foundry 온톨로지에서 사용자는 액션을 적용하여 오브젝트, 속성, 링크를 변경할 수 있습니다. 액션은 사용자 정의 로직에 따라 하나 이상의 오브젝트의 속성을 변경하는 단일 트랜잭션입니다. 액션은 사용자가 특정 속성 편집 대신 전체 목표를 생각하면서 데이터를 처리하고 관리할 수 있도록 합니다.

액션 유형은 사용자가 한 번에 수행할 수 있는 오브젝트, 속성 값, 링크에 대한 변경 또는 편집의 집합을 정의하는 것입니다. 또한 액션을 제출할 때 함께 발생하는 사이드 이펙트 동작을 포함합니다.

예시:

Assign Employee 액션 유형을 생성하여 사용자가 주어진 Employee 오브젝트의 role 속성 값을 변경하는 방법을 정의할 수 있습니다. 이 액션 유형은 사용자가 표준화된 양식으로 새로운 역할을 입력할 수 있도록 파라미터 정의 요구 및 Employee 오브젝트와 새로운 Manager 오브젝트 사이의 링크 자동 생성 방법 규칙을 포함할 수 있습니다.

또한 액션은

변경 사항을 이전 및 새 관리자에게 알릴 수 있는 알림 사이드 이펙트를 포함할 수 있습니다.
인사 담당자와 같은 권한이 있는 직원이 액션을 수행할 수 있는지 확인할 수 있습니다.
이러한 파라미터가 설정되면 HR 직원이 예를 들어 "Melissa Chang"을 "Product Manager" role로 전환하는 액션을 수행할 수 있습니다.

Foundry 온톨로지는 추상 데이터 모델이 아니라 각 온톨로지 개념을 조직의 실제 데이터에 매핑하여 이 데이터 자산이 실제 애플리케이션을 지원하게 합니다. 온톨로지 편집을 통해 사용자의 결정과 통찰력을 기록으로 남겨 데이터 자산이 풍부해지고 그 가치가 증가하게 됩니다.

오브젝트, 속성 값, 링크에 대한 변경 사항은 사용자가 액션을 취할 때 온톨로지에 커밋되며 모든 사용자 애플리케이션에 반영됩니다. 마찬가지로 동일한 액션 로직 및 검증은 모든 사용자 인터페이스 애플리케이션에서 사용할 수 있도록 제공되어 온톨로지에 일관된 편집을 보장합니다. 사용자 편집이 통합된 가장 최신 버전의 오브젝트 데이터는 오브젝트 유형의 writeback 데이터셋에 포착됩니다.
