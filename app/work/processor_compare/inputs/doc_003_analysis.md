# doc_003 Analysis

## 적합성 판단

- 비교 실험용 입력으로 적절하다.
- 정의, 법칙 설명, 역사적 맥락, 사고실험, 결론 확장이 순차적으로 이어져 있다.
- 처리자마다 `definition`, `example`, `evidence`, `expansion` 경계가 어디서 갈리는지 보기 좋다.

## Codex 기준선 절단 판단

### fragment 1
- 범위: 동역학 소개와 강체 정의
- 중심 움직임: `dynamics basic definition`

### fragment 2
- 범위: 뉴턴의 운동과 힘 관계, `F = ma`
- 중심 움직임: `force_motion_relation explanation`

### fragment 3
- 범위: 뉴턴이 일반화된 자연 원리와 만유인력을 찾았다는 설명
- 중심 움직임: `gravity principle discovery`

### fragment 4
- 범위: 포탄 궤적 그림과 사고실험 소개
- 중심 움직임: `thought_experiment setup`

### fragment 5
- 범위: 포탄 사고실험 전개와 공전 상태 설명, 달/위성으로 확장
- 중심 움직임: `orbital_fall explanation`

## 관찰 포인트

- `강체`를 독립 fragment로 떼는지, 동역학 소개와 함께 묶는지 차이가 날 수 있다.
- `F = ma`를 핵심 anchor로 잡는지, `force_motion_relation`으로 추상화하는지 차이가 날 수 있다.
- 사고실험 단락을 `example`, `evidence`, `explanation` 중 무엇으로 읽는지 흔들릴 수 있다.
- 마지막의 `달이나 위성도 같은 중력` 부분을 `bridge`나 `expansion`으로 읽을 가능성이 있다.
