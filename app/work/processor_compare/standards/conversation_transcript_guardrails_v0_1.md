# Conversation Transcript Guardrails v0.1

목적:
- 유튜브 대화 기록, 팟캐스트 기록, 대화형 인터뷰 장문을 비교할 때 입력기와 라벨기 drift를 줄인다.
- `doc_009`에서 드러난 차이를 다음 유사 문서 판정의 기준선으로 고정한다.

## 1. 문서 유형

이 guardrail은 아래 성격의 문서에 적용한다.

- 유튜브 대화 기록
- 팟캐스트 대화 기록
- 인터뷰 transcript
- 발표 후 질의응답 기록
- 챕터 제목과 화자 턴이 섞인 장문 대화

## 2. 입력기 경계 기준

### 패턴 A. 챕터 제목 vs 실제 논지 묶음

- 챕터 제목을 기계적으로 그대로 fragment로 쓰지 않는다.
- 같은 챕터 안에서도 실제 논지 이동이 있으면 분리 후보로 본다.
- 반대로 인접한 챕터라도 같은 논지 흐름이면 통합 후보가 될 수 있다.

### 패턴 B. 화자 턴 vs 의미 묶음

- 화자가 바뀐다고 바로 새 fragment를 만들지 않는다.
- 질문과 답변이 하나의 논지 묶음을 이루면 하나로 유지 가능하다.
- 그러나 서로 다른 예시나 다른 레벨의 메타 논의로 이동하면 분리 후보로 본다.

### 패턴 C. 사례 회고 단계 분절

- 프로젝트 회고는 `시도`, `덜컹`, `가설`, `재시도`, `메타 해석`을 모두 한 덩어리로 뭉개지 않는다.
- 특히 `PoC는 됨`, `핵심 병목`, `세이브포인트 전략`은 separate candidate로 본다.

### 패턴 D. 메타 결론 분리

- 브라운아웃, 인간 덕목, 문제 정의 같은 메타 결론은 별도 fragment 후보로 본다.
- 사례 설명에 흡수되면 후매칭이 불안정해진다.

## 3. scene / role 규칙

### 뉴스 / 도입 문제 제기

- scene = `explanation` 또는 `question`
- role = `thesis` 또는 `problem`

### 도구 / 사이트 사례

- scene = `explanation` 또는 `evidence`
- role = `example`

### 개념 정의

- scene = `explanation`
- role = `definition`

### 하네스 vs 스캐폴딩 같은 대비

- scene = `comparison`
- role = `contrast`

### 병목 / 덜컹 구간

- scene = `explanation`
- role = `problem`

### 마지막 메타 정리

- scene = `reflection`
- role = `thesis` 또는 `expansion`

## 4. 처리자별 drift 해석

### ChatGPT

- 최근 대화 기록 장문에서는 Codex와 비슷한 granularity로 수렴할 수 있다.
- 다만 도입을 `problem`으로, 메타 결론을 `reflection`으로 좀 더 쉽게 밀 수 있다.

실무 해석:
- 과세분화보다 논지 압축 여부를 먼저 본다.
- 챕터별 분절보다 `논지 묶음`을 얼마나 유지하는지 확인한다.

### Gemini

- 챕터와 사례를 큰 요약 블록으로 합치는 경향이 있다.
- 시니어 사례, 세부 프로젝트 회고, 중간 개념 비교를 쉽게 흡수한다.

실무 해석:
- `overmerged_candidate`를 우선 점검한다.
- 메타 결론만 남고 중간 사례가 사라졌는지 확인한다.

### Codex

- 챕터 제목보다 `논지 이동` 기준으로 중간 granularity를 유지하는 기준 후보로 쓴다.
- 절대 정답이 아니라 calibration 중간값으로 유지한다.

## 5. 리포트 우선 점검 항목

대화 기록 장문 비교에서는 아래를 먼저 본다.

1. 챕터 제목 단위 절단과 실제 논지 절단이 얼마나 다른가
2. 화자 턴을 그대로 자르는가, 논지 묶음으로 자르는가
3. 사례 회고를 단계적으로 유지하는가
4. 하네스/스캐폴딩/문제 정의를 별도 개념 단위로 세우는가
5. 브라운아웃과 인간 덕목 결론을 별도 메타 정리로 유지하는가

## 6. 잠금 문장

대화 기록 장문에서는 화자와 챕터보다 논지 이동이 우선이다.
챕터 제목을 그대로 자르지 말고, 사례 회고와 메타 결론을 무의미하게 흡수하지 않는다.
Codex는 중간 granularity 기준을 유지하고,
ChatGPT의 논지 압축과 Gemini의 대묶음을 calibration 신호로 읽는다.
