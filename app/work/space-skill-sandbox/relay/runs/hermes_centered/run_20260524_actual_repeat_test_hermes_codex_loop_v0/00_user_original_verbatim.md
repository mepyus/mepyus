Hermes는 사용자 지시를 원본 그대로 보존/해석하고, Codex에게 CLI/script bridge로 원본 관련 공간자료 retrieval을 요청한다. Codex가 가져온 공간자료를 Hermes가 원본+공간+모델값으로 재해석/재반영/재이해하고 실행한다. Hermes는 Codex가 무엇을 가져왔는지, 재해석 내용과 실행 trace를 기록하고, Codex가 쉽게 읽을 수 있게 만든다. Codex CLI에서 사용자가 직접 하는 것은 이후 공간 숙성 판단/작업이다. Gemini는 Codex script-chain 내부에서 공간 탐색/분석 보조로 사용된다. Codex/Gemini API 직접 호출은 하지 않는다.
