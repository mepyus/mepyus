# Space Governance

Codex classifies new inputs, retrieves pre-execution space, analyzes Hermes execution, judges space delta, decides whether Gemini exploration is needed, and proposes HOLD-only maturation.

Use Gemini only when bounded evidence is insufficient:
- unclear layer boundaries
- semantic flattening suspected
- many nearby artifacts require cluster scan
- Hermes trace conflicts with index or prior reports
- maturation candidate crosses multiple layers

Do not use Gemini for simple status checks or when required records already decide the issue.

Maturation means proposing how space should remember work. Valid outputs include proposed index additions, proposed layer assignments, task-packet rules, reentry schemas, stale/superseded notes, missing-handle fixes, and validation packets.
