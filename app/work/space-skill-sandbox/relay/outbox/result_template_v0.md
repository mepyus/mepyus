# Relay Outbox Result Template v0

## 1. Verdict
*작업의 최종 성공 여부 (OK / PASS_WITH_NOTE / HOLD / USER_JUDGMENT_REQUIRED)*

## 2. Created Files
*새로 생성된 파일 목록*

## 3. Modified Files
*수정된 파일 목록 (원칙적으로 없음)*

## 4. Skills Consulted
*참조된 스킬 후보 목록*

## 5. Routing Result
*가이드에 따른 라우팅 판단 근거 및 결과*

## 6. Stop Points
*감지된 위험 지점 및 조치 내용*

## 7. Validation Summary
*검증 결과 요약*

## 8. User Judgment Required
*사용자의 판단이 필요한 지점 명시*

## 9. Next Recommendation
*다음에 수행할 작업 제안*
