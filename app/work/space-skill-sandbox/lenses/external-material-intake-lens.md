# External Material Intake Lens

## Status

```yaml
state: lens_candidate
baseline: false
```

## What this lens reads

When one external material enters, read structure before value.

Ask:

- What problem is the maker solving?
- What behavior does the structure encourage?
- What is directly useful to this space?
- What is useful but dangerous?
- What should be held, borrowed later, or rejected?
- Does this material create pressure toward implementation, schema, automation, or baseline?

## Core distinction

```text
external value != internal adoption
similarity != fit
useful idea != locked rule
summary != evidence
```

## Output posture

The lens should lower material into:

- same
- similar_but_dangerous
- different
- borrow_later
- reject_for_now

## Do not

- Do not summarize only.
- Do not treat external material as authority.
- Do not import external methods as internal rules.
- Do not jump to implementation.
