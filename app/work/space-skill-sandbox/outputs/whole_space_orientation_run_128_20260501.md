## What The Whole Space Is

The current space is not mainly a package queue or a cluster result map.

It is an operating rereading surface:

```text
source material
-> first-order trace
-> memory packet / process residue
-> second-order rereading
-> hold / weak / fallback / blocker
-> line thickening
-> reflux into future interpretation, engine work, and human-facing language
```

The space must come first. LLM output comes later as recorder, arranger, worker return, or review material.

## Higher Principles

### 1. Space First / LLM Last

Do not let a polished LLM structure manufacture meaning.

Meaning should come from accumulated traces, line movement, reread loops, and provenance. LLMs may help read, arrange, verify, and draft after the space has produced material.

### 2. Open Interpretation Space

Hold, weak, fallback, blocker, residue, and failure are not trash.

They are deferred openness and future comparison memory. The goal is not to close interpretation too early.

### 3. Reread First / Lock Later

Do not lock a line, hub, rule, or package because one reading looks strong.

Repeat:

```text
same line
-> different object
-> different material
-> different folder / runtime / view
-> only then provisional condensation
```

### 4. A / B / C Reading Order

Use the current layered judgment:

```text
A = structure before freeform agenting
B = bounded surface over universal agent freedom
C = maintenance and validation discipline
```

Read live work in this order:

1. What must be fixed before expansion?
2. What bounded surface / role / attach boundary is protected?
3. What remains hold / watch / candidate / validation-only?

### 5. Integrated Engine Three-Surface Reading

Do not collapse the project into one UI or one agent loop.

```text
User Surface = purpose declaration / team operation
VectorFL Surface = line / relation / gap / pending / reflux
Engine Surface = ingest / processing / validation / trace-memory-return
```

The current work must identify which surface it belongs to before any action.
