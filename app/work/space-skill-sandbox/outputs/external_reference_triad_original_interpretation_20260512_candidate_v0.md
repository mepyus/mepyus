## 4. Source A Pull - Brunch Deterministic Architecture

What is relevant:

```text
The source frames deterministic architecture as controlling variables and output through workflow and prompt design.
It demonstrates a multi-role production pipeline where downstream workers do not see the whole system.
It emphasizes fixed inputs, role boundaries, episode/section mapping, entity control, continuity control, and output protocol.
```

Pulled judgment:

```text
When a worker cannot infer the whole space,
the packet must carry enough deterministic boundaries:
  what to read
  what not to read
  role
  assigned scope
  density requirement
  continuity coordinates
  forbidden drift
  output protocol
```

Downshift:

```text
This does not mean our space becomes deterministic.
Only the execution packet becomes temporarily closed.
```

## 5. Source B Pull - Flamehaven Fluent Certainty

What is relevant:

```text
The source warns that AI can make unfinished systems feel complete through fluent internal coherence.
It distinguishes internally smooth documentation from working systems with limitations, tradeoffs, and visible failure.
It asks what would falsify what is being built.
```

Pulled judgment:

