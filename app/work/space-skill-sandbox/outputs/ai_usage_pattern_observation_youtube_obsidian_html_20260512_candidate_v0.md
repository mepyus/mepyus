## 2. What Other People Are Doing With AI

The transcript shows AI being used less as a direct answer machine and more as a production layer inside a personal workspace:

```text
Obsidian note
-> optional linked-note context pack
-> Codex CLI or Claude Code CLI backend
-> design/purpose preset
-> HTML artifact
-> GitHub Pages/shareable URL
-> optional feedback/comment layer
```

The important shift is not "Markdown to HTML" by itself.

The important shift is:

```text
AI is placed between a private knowledge workspace and a public artifact surface.
```

## 3. Usage Primitives Observed

| Primitive | What it does | Why it matters locally |
|---|---|---|
| Source workspace | Obsidian remains the writing surface | The original space is preserved instead of replaced |
| Context Pack | Linked notes can be included | Context boundary becomes a judgment problem |
| CLI backend | Codex/Claude CLI performs generation | Agent power is hidden behind a simple UI |
| Preset selection | User selects purpose/design | Output intent is closed before execution |
| Artifact output | HTML is generated | Output is inspectable and shareable |
| Publish target | GitHub Pages is used | Deployment becomes part of the AI pipeline |
| Feedback layer | Disqus/GitHub comments can be attached | Artifact can become an interaction surface |
| Setup wizard | CLI paths, timeout, token, repo are configured | Setup friction is moved into guided configuration |
