# Whole-Space Orientation Atlas Candidate v0

## 1. Status

Status: candidate orientation atlas
Authority: not baseline / not official workflow / not source-space policy
Scope: whole-space orientation surface

This atlas is not ontology, graph, schema, automation, router, controller, or folder restructuring plan.

It is a candidate orientation surface for future User / ChatGPT / Codex / Gemini sessions.

## 2. What This Space Is

The VectorFL / integrated-engine working space is an accumulated memory, philosophy, process, judgment, and execution-trace layer.

It contains:

- philosophical direction
- operating principles
- baseline / candidate / watch distinctions
- sandbox experiments
- package closeouts
- external lens reinterpretations
- runtime traces
- process memory
- line-axis reading materials
- user / engine translation material
- Codex / Gemini review traces

The space should not be read as a flat folder tree. It should be read as a layered working memory where authority, source refs, and current position matter.

## 3. Space vs Sandbox

Space:

- accumulated memory and direction layer
- contains philosophy, reports, runtime records, current-position memory, source/provenance material, engine-oriented material, and sandbox-derived candidate references

Sandbox:

- bounded experiment / observation / worker-behavior testing layer
- located mainly under `app/work/space-skill-sandbox/`
- contains packages, runs, outputs, review notes, lenses, worker guides, and relay artifacts

Sandbox outputs are not source-space law.

Sandbox tools are not official workflows.

Sandbox notes may become candidate references, not automatic system rules.

## 7. Authority / Status Vocabulary

Descriptive, not policy:

- baseline: stronger accepted reference or source-like anchor; do not assign without explicit approval
- candidate: proposed / useful / reviewable material without baseline authority
- watch: preserved risk or unresolved issue
- hold: do not advance without decision or clarification
- accepted: accepted in a bounded sequence; not automatically baseline
- rejected: not used for current direction
- invalid: not valid for sequence evidence
- orphaned: preserved observation detached from active sequence authority
- VOID: non-authoritative or voided record status
- quarantine: preservation area/status for unsafe or misnumbered material; not a general policy
- candidate evidence: evidence usable at candidate/reference level only
- candidate reference: reference material, not authority
- current-position entry: compact re-entry memory
- reusable setting: candidate operating shape that may be copied and detail-adjusted
- source map: provenance/support map, not citation baseline
- line-axis reference: support note for axis reading, not ontology edge
