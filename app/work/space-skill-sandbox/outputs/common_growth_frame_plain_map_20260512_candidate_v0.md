## 2. 한 문장

```text
새 입력은 그냥 저장되는 것이 아니라,
기존 공간과 만나 Line과 Axis를 만들고,
필요하면 Pipeline 후보가 되어 샌드박스나 닫힌 실행 패킷으로 시험되고,
그 결과가 Growth Trace로 원본 공간에 돌아온다.
```

## 3. 가장 짧은 지도

```text
Original Space
-> New Input
-> Contact with existing space
-> Line / Axis detection
-> Pipeline Candidate only if justified
-> Sandbox or bounded execution
-> Failure / Falsification check
-> Return-to-Space
-> Active Re-entry Surface update candidate
```

## 4. 중요한 분리

```text
원본 공간 = 깊게 둔다.
재진입 표면 = 얇게 둔다.
샌드박스 = 가볍게 시험한다.
실행 패킷 = 충분히 닫는다.
회수 = 실패 조건과 함께 원본으로 돌린다.
```
