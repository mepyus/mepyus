## 5. Axis Candidates

### Axis 1. Depth / Surface Axis

```text
Original space stays deep.
Active re-entry surface stays thin.
```

Protects:

```text
space depth without re-entry overload
```

Overreach:

```text
turning the active surface into a long registry
```

Failure condition:

```text
The surface increases explanation cost instead of reducing it.
```

### Axis 2. Growth / Non-Premature Pipeline Axis

```text
Line and Axis can appear before a Pipeline Candidate exists.
```

Protects:

```text
not forcing every useful idea into a pipeline
```

Overreach:

```text
declaring a pipeline before repeatability, failure condition, and return path are visible
```

Failure condition:

```text
The label "Pipeline Candidate" appears but cannot be tested on another input.
```

### Axis 3. Execution Boundary Axis

```text
Original space is open, but execution packets must be closed enough.
```

Protects:

```text
workers from being asked to infer the whole space
```

Overreach:

```text
applying deterministic packet logic to the whole original space
```

Failure condition:

```text
A worker packet needs hidden context or returns unusable output because coordinates/boundaries were unclear.
```

### Axis 4. Falsification / Fluent Certainty Axis

```text
Fluent structure is not validation.
```

Protects:

```text
the space from becoming internally coherent but externally untested
```

Overreach:

```text
using doubt as generic paralysis instead of naming specific failure tests
```

Failure condition:

```text
The structure cannot say what would make it wrong, weak, or not useful.
```
