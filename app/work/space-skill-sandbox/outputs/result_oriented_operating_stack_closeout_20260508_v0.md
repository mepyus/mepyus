## 9. Stop Criteria

Stop creating new packages when:

- the next step is only bigger testing without new purpose
- a result is safe but low-value
- Codex would only create another recovery note without reusable value
- Hermes would exceed 5 active surfaces by default
- Gemini would be asked to validate/prove instead of test
- QMD would become memory/search authority
- user judgment is needed
- routing is ambiguous
- result usefulness is unclear

At stop:

- ask user for direction, or
- hold, or
- route to the smallest sufficient role.

## 10. Future Real Task Rule

For future tasks:

1. Start with user purpose.
2. Determine expected useful result.
3. Choose the smallest sufficient route.
4. Use external tools only if they add value.
5. Do not create a package unless the task needs package-level handling.
6. Do not create recovery notes for raw trace only.
7. Preserve candidate-with-watch unless user explicitly promotes.
