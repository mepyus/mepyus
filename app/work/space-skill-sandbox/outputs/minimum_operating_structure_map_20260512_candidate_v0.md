## 3. The Minimum Structure

```text

Layer 5. Flow Selection
Layer 6. Blurry Field Check
Layer 7. Sandbox / Worker / HOLD-WATCH Decision
Layer 8. Return-to-Space
Layer 9. Re-entry Update Candidate
```

## 4. Layer Roles

| Layer | Role | Must not become |
|---|---|---|
| Original Space / Reservoir | deep source and memory layer | product, fixed pipeline |
| Asset Family Map | know what exists | registry, ontology |
| Active Re-entry Surface | thin current surface | long manual |
| Trigger / User Purpose | current reason to pull | automatic route |
| Flow Selection | choose smallest useful flow | router |
| Blurry Field Check | identify missing structure | mandatory card set |
| Sandbox / Worker / HOLD-WATCH Decision | choose action mode | automation |
| Return-to-Space | recover result/failure/watch | approval |
| Re-entry Update Candidate | preserve next useful start | current-position by default |

## 5. Operating Question Sequence

Use this sequence before adding more structure:

```text
1. What triggered this?
2. Which existing asset family does it touch?
3. Which active flow is the smallest useful one?
4. Which field is blurry?
5. Does this need thought, sandbox, worker packet, WATCH, or HOLD?
6. What would make this fail?
7. How will the result return?
8. What should be visible next time?
```

## 7. What Is Structurally Missing

The missing piece is:

```text
Sandbox / Worker / HOLD-WATCH Decision Gate
```

Why:

```text
We can now identify assets, trace recovery, active flows, and Line/Axis candidates.
But we still need a small decision gate for:
  when to sandbox,
  when to send a worker packet,
  when to hold,
  when to keep watch,
  when to stop for user judgment.
```
