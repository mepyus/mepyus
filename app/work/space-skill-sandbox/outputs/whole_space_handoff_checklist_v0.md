# Whole-Space Handoff Checklist v0

## Status

- status: checklist candidate
- baseline: false
- automation: false
- schema: false
- controller: false

Use this before giving work to Gemini, Codex, ChatGPT, or a future session.

## 1. Entry Surface

Check:

```text
current whole-space orientation:
current sandbox position:
last trusted point:
accepted / hold / invalid state:
next allowed action:
forbidden moves:
```

Do not treat newest sandbox run as whole-space truth.

## 2. Space Frame

Confirm the work preserves:

```text
space first / LLM last
reread first / lock later
open interpretation space
A/B/C layered reading
User / VectorFL / Engine surface split
```

## 3. Role Routing

```text
User = purpose / approval / final control
ChatGPT = design and structural validation
Codex = structural judgment / packet / review
Gemini = bounded observation / long reading / execution
```

Codex conserves tokens. Gemini is first route for long reading or execution.

## 4. Sandbox 15 Placement

Use the 15 principles as sandbox audit lenses only.

Do not promote them into source-space law or engine baseline.

## 5. Process Memory Placement

Use process memory as:

```text
entry-point memory
handoff grammar
failure recovery
authority separation
HOT / WARM / COLD reading guide
```

Do not install `AIMemory/`, migrate folders, or create automation from it.

## 6. Promotion Barriers

Before proceeding, explicitly check:

```text
Package 032 artifact read approved? 
Package 033 promotion approved?
baseline change approved?
automation/schema/ledger/controller requested?
```

Default answer is no unless User explicitly approves.

## 7. Return Review

Every worker return must be classified:

```text
accepted evidence
accepted with caution
candidate
hold
invalid for sequence
orphaned observation
reference-only failed attempt
```

Preserved does not mean authoritative.
