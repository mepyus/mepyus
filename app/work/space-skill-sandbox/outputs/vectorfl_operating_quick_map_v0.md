# VectorFL Operating Quick Map v0
## 0. Status
- quick map / re-entry surface only; live-use with watch; not baseline, schema, registry, routing authority, automation, mandatory first-read, or replacement for user judgment.
- basis: required candidate docs + Trial 017 USER_PROVIDED_SUMMARY / GEMINI_TRIAL_EVIDENCE.
## 1. Core Sentence
공간은 원칙을 지킨 결과가 아니라, 쓸 수 있는 판단을 회수한다.
## 2. Operating Flow
User Purpose -> Camera: what/where to observe -> Lens: how to read -> Smallest sufficient context -> One neighbor only if missing layer appears -> Mission Packet / Map -> Worker result -> Usefulness Gate -> Return Placement -> Compounding Check -> Next Work.
## 3. Lens / Bundle Map
- Core Judgment Lens: main judgment only.
- Asset / Provenance Lens: capsule, policy mutation, recoverable asset.
- Tool Calibration Lens: tool strength, drift, safe scope.
- Routing / User Trigger Lens: user wording, route drift, supervisor drift.
- Causal Maturation Lens: bounded RUNLOG slice, why-did-this-change.
## 4. Progressive Loading Rule
- Start with the smallest sufficient lens.
- Do not load all docs/lenses by habit.
- If insufficient, request exactly one neighbor: missing_layer / why insufficient / requested_neighbor / expected useful result.
## 5. Return Placement
RETURN_TO_SPACE_VALUE / RETURN_TO_SPACE_VALUE_WITH_WATCH / COMPARISON_ASSET_WITH_WATCH / WATCH / RAW_TRACE / HOLD / DISCARD.
## 6. Compounding Check
What does this recovered judgment make easier next time?
If nothing, keep as raw trace / watch / hold.
## 7. Tool Role Reminder
- Codex-light: file-grounded setup, patches, structural checks.
- Gemini-heavy: broad reading, synthesis, external reference translation, audits.
- Supervisor / ChatGPT: route choice, downshift, provenance check, user-facing judgment.
- User: final direction and promotion decision.
## 8. Do Not
- Do not turn lenses into schemas.
- Do not turn tier map into routing authority.
- Do not read full RUNLOG by habit.
- Do not promote candidates without user judgment.
- Do not keep building structure when real use is needed.
## 9. Watch
10-document burden; ceremony replacing judgment; map becoming manual; provenance becoming filler; fresh worker under-context; user language disappearing.
## 10. Next Use
Use this map when context is lost, a new worker enters, or a mission packet needs compact orientation; otherwise start from the actual user purpose.
## 11. Final Note
This quick map compresses the current operating stack for re-entry and should be revised only after real-use friction appears.
