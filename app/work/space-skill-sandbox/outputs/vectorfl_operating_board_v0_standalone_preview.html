웹 검색 후에도 결론은 더 큰 시스템이 아니라 더 얇은 운영 표면이다. VectorFL Board는 agent dashboard를 복제하지 않고, trace와 pause를 사람 판단으로 회수하는 표면이어야 한다.

Usable

  • Trace / run / session 개념은 movement log의 근거가 됨
  • Interrupt / resume 개념은 Human Gate의 근거가 됨
  • Pause Reason / Waiting On / Resume Condition은 얕은 표시 필드로 충분함
  • Agent Skills는 autonomy support 비교 재료로 유지 가능함

WATCH / HOLD

  • WATCH: observability가 full dashboard 요구로 커지는 위험
  • WATCH: HITL이 approval machine으로 오해되는 위험
  • WATCH: resume이 automatic retry로 오해되는 위험
  • HOLD: automation, registry, schema, live agent wiring
