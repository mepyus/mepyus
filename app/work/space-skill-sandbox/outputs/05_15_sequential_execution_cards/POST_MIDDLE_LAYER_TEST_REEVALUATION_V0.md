```text

```

The selector inserted:


Result:
  useful.

But:
  one dry-run does not prove general behavior.

## 5. Current strongest rule

The strongest surviving rule is not the 0-9 naming.

It is:

```text
Do not let raw input jump straight to reusable action.
```

Expanded:

```text
raw signal
-> preserve arrival layer
-> test frame/evidence
-> check boundary/authority
-> select smallest safe action
-> require follow-up if action affects reality
-> stop if promotion/reusable surface is requested without approval
```

This is the actual reusable behavior.

## 6. Current weakest point

The weakest point is still over-articulation.

Symptoms:

```text
many documents
many dry-runs
many named modes
candidate pile that can look like registry
mode thresholds that can look like policy
```

Countermeasure:

```text
future outputs should be shorter
use existing mode thresholds instead of adding theory
prefer real-input tests over explanatory docs
```

## 7. Updated mode rule with 7 nuance

```text
plain chat:
  only 0,1,5

simple answer:
  0,1,5 + trivial 2

light review:
  small 2/3/6, no authority jump, no auto-fail, no promotion action

full review:
  material 2/3/4/6 with real risk, missing evidence, unclear authority, follow-up owner, or 7_topic

layer-shift:
  8/9 materially changes meaning without requiring stop

stop:
  7_action, 3 auto-fail, or action requested without authority
```
