## 2. Method correction

Bad method:

```text

Find local assets that seem to match.
Conclude alignment.
```

Corrected method:

```text
Start from local asset contracts.
Extract their native tests.
Apply those tests to 05-15 outputs.
Mark pass, partial, fail, or too-early.
```

This matters because a good lens can still overfit.
