## 5. Core Frame To Build

Design the future lane as four layers:

```text
1. Execution Layer
   Hermes runs real work: company tasks, B2B workflows, content ops, customer response, external tool work, local runner tasks, and later approved automation.

2. Run Trace Layer
   Hermes produces reports, receipts, logs, outputs, decision notes, failure notes, and evidence packets.

3. Recovery Gate
   Codex classifies Hermes outputs as discard / receipt / residue / candidate / component / space update proposal / STOP.

4. Maturation Layer
   Gemini compares many recovered traces, finds patterns, proposes names, thresholds, vessels, or higher-level concepts without granting authority.
```

Keep the short rule:

```text
Hermes produces.
Codex filters.
Gemini matures.
Space remembers selectively.
```

## 6. Recovery Classes

Define these recovery classes clearly:

```text
discard:
  one-off byproduct; no need to preserve beyond task result.

receipt:
  evidence that a task ran, with scope, files, tools, and result path.

residue:
  meaningful trace that may matter later but is not reusable yet.

candidate:
  reusable judgment, threshold, pattern, prompt, script idea, or operating behavior.

component:
  named function/part that can be reused inside a bounded lane.

space_update_proposal:
  possible future update to current surface, baseline, guide, spec, registry, workflow, ontology, or memory, but not approved.

STOP:
  authority, memory, automation, cron, skill, config, baseline, policy, registry, workflow, ontology, current-position, output_manifest, or local authority mutation pressure.
```

## 7. Apply IIC / SOF / MOL / RML

Map the vessels to the future Hermes-main lane:

```text
IIC:
  reads the incoming work request and selects depth/mode before Hermes executes.

SOF:
  decides what Hermes may reference, what Hermes may write, and whether any result can move toward space.

MOL:
  maps tool routes, scripts, automation harnesses, browser/file/terminal actions, and handoff paths.

RML:
  recovers report/receipt/log/provenance from Hermes execution after the run.
```

Preserve:

```text
SOF current authority wins.
RML evidence strengthens confidence but cannot grant authority.
IIC can select read depth but cannot grant execution or promotion.
MOL maps execution machinery but cannot automate by default.
If any vessel returns STOP, the whole lane stops.
```
