## 3. Queue Split

### QI-1 Codex Result

recovered:
  Codex result is execution evidence, not structural authority.

WATCH:
  patch success -> direction approval
  run record -> baseline
  repo state -> task authority

HOLD:
  baseline promotion
  current-position update
  output_manifest update
  broad refactor

boundary:
  command_execution: possible / yes
  file_write: possible / yes
  baseline_promotion: possible

  COMPRESS; CONFLICT if result implies structural direction
