## 5. Rereading Method

Do not produce a simple inventory.

Use this sequence:

```text
1. Read current authority / current reality.
2. Read folder role boundaries.
3. Scan folder distributions and naming clusters.
4. Map scattered assets into the 0-9 family frame.
5. Identify overlaps, gaps, and duplicated naming.
6. Lift one level higher:
   What larger vessels should hold these families?
7. Keep each proposed vessel as candidate, not promoted ontology.
8. Suggest how small vessels should grow inside each large vessel.
```
