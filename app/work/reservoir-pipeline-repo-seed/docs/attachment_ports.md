# Pump Attachment Ports

Ports are temporary handles for attaching a pipeline to the reservoir.

They are not APIs, permissions, registries, or permanent routes.

| Port | Pulls from reservoir | Typical temporary pipeline | Return form |
|---|---|---|---|
| Philosophy Port | Core Philosophy | purpose framing | candidate principle with watch |
| Judgment Port | Judgment Capsule | comparison / decision support | return-to-space value |
| Trace Port | Process Trace | process reread / mistake recovery | process memory light |
| LACL Port | Camera / Lens / Line / Axis | reading packet / observation map | lens or camera candidate |
| Mission Port | Mission Pattern | worker packet setup | mission packet candidate |
| Return Port | Return Pattern | result packaging | return placement |
| Boundary Port | Watch / Boundary | preflight / drift check | watch or hold |
| Artifact Port | Implementation Artifact | sandbox trial / code or UI inspection | experiment result with watch |

## Port Rules

```text
one purpose may use multiple ports
ports attach only after a purpose appears
ports detach after the run
ports do not imply worker authority
ports do not update current-position
```
