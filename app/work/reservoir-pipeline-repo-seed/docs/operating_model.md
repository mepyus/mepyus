# Operating Model

## Core Sentence

The space is not the pipeline. The space is the reservoir that makes pipelines possible.

## Operating Flow

```text
User Purpose
-> Reservoir Access Gate
-> Asset Family Selector
-> Pump Attachment Frame
-> Temporary Pipeline
-> Sandbox Derivation
-> Usefulness Check
-> Return Channel
-> Next Condition
```

## Role Split

```text
User = purpose, selection, final promotion decision
ChatGPT = direction validation and role drift check
Codex = structure, file-grounded packaging, repo-seed maintenance
Gemini = bounded evidence inventory and broad reading when explicitly assigned
CLI = concrete command execution only when explicitly scoped
```

## Non-Promotion Rule

```text
candidate reference != approval
watch item != law
run record != authority
helper != workflow
port != API
asset family != registry
pipeline != original space
derivative != reservoir
```
