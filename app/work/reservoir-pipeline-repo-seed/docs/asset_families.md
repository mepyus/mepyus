# Reservoir Asset Families

Use these as loose reading aids only.

| Asset family | Pull when purpose needs | Must not become |
|---|---|---|
| Core Philosophy | direction, meaning, why this matters | policy or implementation command |
| Process Trace | how judgment formed, failed, corrected, or returned | full history crawl |
| Judgment Capsule | compact recovered decision unit | capsule registry |
| LACL / Camera / Lens | observation point and reading method | ontology |
| Mission Pattern | how workers were tasked | automatic router |
| Return Pattern | how outputs came back into space | ledger |
| Watch / Boundary | risks, non-promotions, drift warnings | law unless user promotes |
| Implementation Artifact | code, UI, preview, concrete trial result | proof of adoption |
| External Reference | outside material read through space criteria | imported authority |

## Selection Rule

Select the smallest asset family set that can serve the current purpose.

If the purpose is unclear, do not pull from the reservoir.
