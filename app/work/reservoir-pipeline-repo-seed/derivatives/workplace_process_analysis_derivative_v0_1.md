## 7. Decision-Point Map v0.1

| Step | Decision question | Evidence needed | Failure mode | Reservoir return |
|---|---|---|---|---|
| request received | Is the purpose clear enough to enter the process? | request text, requester, deadline, target output | unclear request enters pipeline as noise | purpose-gate wording |
| material check | Is the material sufficient for first pass? | files, context, constraints, missing items | repeated material requests fragment the trace | source-intake checklist candidate |
| owner assignment | Who has decision responsibility? | role map, approval line, task type | hidden owner gap delays work | role-boundary watch |
| draft | What output surface is appropriate? | examples, expected audience, use case | overbuilt artifact before purpose stabilizes | output-surface selection rule |
| internal review | What standard decides pass/revise? | review criteria, risk list, user purpose | subjective review repeats without learning | judgment capsule candidate |
| approval | Who can release or hold? | authority line, explicit approval record | worker confidence becomes permission | user decision gate reminder |
| external delivery | What can be safely sent out? | final artifact, external boundary, audience | premature externalization | external-use watch |
| feedback | What changed after delivery? | feedback text, mismatch, accepted/rejected changes | feedback disappears from process trace | feedback-to-trace return |
| revision / close | What closes the loop? | delta, final decision, unresolved watch | no closeout record | closeout/return record requirement |
