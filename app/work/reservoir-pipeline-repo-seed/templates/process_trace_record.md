# Process Trace Record

## Purpose

Record how a pipeline or derivative was created.

## User Purpose

```text
What did the user want to make possible?
```

## Source Materials Read

```text
Which files, notes, records, or external references were read?
```

## Camera / Lens Used

```text
What was observed?
How was it read?
```

## Key Judgments

```text
What decisions shaped the pipeline?
What changed during the process?
What was held or rejected?
```

## Outputs Created

```text
Which files or artifacts were produced?
```

## Return To Space

```text
What returned as reusable judgment?
What placement label was used?
```

## Watch

```text
What must not be inferred from this process?
```

## Next Use

```text
How should a future pipeline use this trace?
```
