# Reservoir Access Gate

## Purpose

Use this before touching the reservoir.

## Gate Questions

```text
1. What is the user's current purpose?
2. Why does this need the reservoir rather than a one-off answer?
3. Which original-space area is relevant?
4. What must not be pulled?
5. What return route is expected?
```

## Gate Decision

Choose one:

```text
ALLOW_TEMPORARY_PUMP
ASK_USER_FOR_PURPOSE
HOLD_AS_RAW_MEMORY
USE_ONE_OFF_RESPONSE_INSTEAD
```

## Boundary

This gate clarifies scope. It does not grant permission or authority.
