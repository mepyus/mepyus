## Mock Process

```text
request received
-> material check
-> owner assignment
-> draft
-> internal review
-> approval
-> external delivery
-> feedback
-> revision / close
```

## Small Process Map

| Step | Decision point | Evidence used | Possible bottleneck | Return to space |
|---|---|---|---|---|
| request received | accept / clarify / reject | request text | unclear purpose | purpose gate wording |
| material check | enough / missing | attached material | repeated material requests | intake checklist candidate |
| owner assignment | who owns this? | role map | responsibility gap | role-boundary watch |
| draft | what shape? | prior examples | overbuilding | output-surface boundary |
| internal review | approve / revise | review criteria | subjective judgment | judgment capsule candidate |
| approval | release / hold | authority line | hidden permission drift | user decision gate |
| external delivery | send / wait | final artifact | premature externalization | external-tool watch |
| feedback | accept / dispute / clarify | user or client feedback | feedback lost | process-trace return |
| revision / close | close / reopen | delta from feedback | no closeout record | return record template |
