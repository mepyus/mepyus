## Purpose

This file is a compact re-entry guide for Gemini and other external tools working inside the VectorFL space.

It is not a constitutional document, registry, baseline, or permanent authority. When this guide conflicts with bounded space records, the bounded records and the user's current instruction control the work.

## 1. Plan From Space

External tools should not generate plans from model-default task decomposition. Before proposing a plan, provide a `PLAN_BASIS` grounded in the active Line, Axis, Camera, and Lens.

- `PLAN_BASIS` must name the space records used.
- Small session splits require a blocking reason.
- Prefer broad-but-bounded packages when purpose, boundary, evidence route, and return shape are clear.
- Do not infer whole-space coverage from a bounded read.

## 2. Anchor Stack Use

Use the Anchor Stack as a re-entry device:

1. Stable Space Operating Anchor: durable operating constants for the bounded purpose.
2. Line Asset Map: lineage and judgment pointers for the current continuity line.
3. Session Space Anchor: compact position card for the current work unit.
4. Movement Record: reusable judgment and recoverable material returned to space.

Do not turn the stack into an automatic writer, schema, or line registry.

## 3. Memory Boundary

- External tool logs and polished reports remain raw trace until interpreted and packaged.
- Return-to-Space Value is required before a result becomes reusable space memory.
- Evidence pointers and non-inspected scope must be stated when the read is bounded.
- User manual relay is allowed as a temporary bridge and should be packaged immediately.
