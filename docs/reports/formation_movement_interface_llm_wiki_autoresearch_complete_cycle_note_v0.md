## 5. simulated Codex comparison output

This section represents the kind of bounded comparison output Codex should produce from the merged material.

### output type

`comparison_output_draft`

### output body

#### A. formation-side contribution

- `LLM-Wiki` provides a compiled intermediate layer:
  raw sources remain immutable, the wiki is a maintained artifact, schema governs ingest/query/lint
- it strongly supports:
  accumulation, reread, cross-reference maintenance, contradiction tracking, and compounding artifact logic

#### B. movement-side contribution

- `autoresearch` provides a constrained execution loop:
  bounded scope, fixed metric, fixed budget, keep/discard iteration, explicit agent program file
- it strongly supports:
  bounded movement, verification before keep, and disciplined iteration instead of unconstrained autonomy

#### C. schema role

- both sources elevate a lightweight schema/document:
  `AGENTS.md`-like discipline for LLM-Wiki
  `program.md` for autoresearch
- common signal:
  the agent is not treated as a generic chatbot but as a process-constrained operator

#### D. validation role

- `LLM-Wiki`:
  lint and query feed back into the maintained artifact
- `autoresearch`:
  metric/check/keep-discard loop determines whether change survives
- common signal:
  output should not survive only because it exists; it must re-enter a gate

#### E. overreach risks

- over-importing `LLM-Wiki` would collapse the package into a persistent wiki doctrine
- over-importing `autoresearch` would collapse the package into an autonomous optimization loop doctrine
- merging them too quickly would confuse:
  accumulation logic with execution logic

### compressed comparison output

```text
LLM-Wiki is stronger on formation-side accumulation and maintained intermediate artifacts.
Autoresearch is stronger on movement-side constrained execution and keep/discard verification loops.
Both strengthen schema-guided agent behavior and anti-shortcut discipline.
Neither is direct evidence for the internal package ontology.
```
