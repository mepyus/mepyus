## 4. how well the lexicon held

The lexicon held well enough for controlled explanation.

The required order worked:

```text
current operating status
-> protected authority/boundary
-> what remains closed
-> possible re-entry/decision
-> what not to infer
```

When this order was followed:

- `watch keep` did not become patch queue
- `hold` did not become discard
- `collision stop condition` did not become error handling
- `reject / conflict` did not become global badness
- `carry-forward` mostly avoided roadmap commitment
- `workspace ownership` stayed authority/provenance, though still thin

## 5. entries that survived well

Survived well:

- `watch keep`
- `hold`
- `collision stop condition`
- `reject / conflict`
- `not promoted`
- `user decision / package opening authority`

Reason:

- these were reinforced by current operating state and official reopen/closed-mode language.

## 6. entries still fragile

Still fragile:

- `workspace ownership`
- `carry-forward`
- `reject / conflict`

Why:

- `workspace ownership` still sounds like folder ownership unless authority is repeated.
- `carry-forward` still sounds like later commitment if the future angle is overemphasized.
- `reject / conflict` survives when scoped, but the word "reject" pulls toward global judgment.

## 7. external harvest decision

External harvest should remain closed.

Reason:

- the lexicon survived a controlled usage trial but still has fragile entries.
- outside phrasing could make the explanation smoother while reintroducing folder/backlog/error language.
- one more internal adjustment or guide layer is safer before external translation rules.

## 8. next round recommendation

Recommended next round:

- `provisional human explanation guide v0`

Reason:

- the lexicon is now usable, but the retention depended heavily on explanation order.
- a guide can lock the explanation order and anti-flattening checks without adding final terms.
- another reread round would be less useful than turning the proven order into a reusable guide.
- external harvest remains premature.

Required boundary for next round:

- no final glossary
- no UI copy
- no wording patch
- no scaffold/manifest/read-map changes
- no external style guide
- no new feature discussion

## 9. closeout sentence

The bridge lexicon survived a controlled operating-mode explanation trial, but its safe use depends on a specific explanation order. The next step should be a provisional human explanation guide v0, not external harvest or final wording.
