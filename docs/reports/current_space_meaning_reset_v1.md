# current_space_meaning_reset_v1

## 1. purpose

- 이번 문서의 목적은 현재 `vectorfl_replica` 공간을 점/군집 결과면이 아니라, 입력과 흔적과 재독해를 운영자가 따라가는 운용면으로 다시 정의하는 것이다.

## 2. why point/cluster is not the center yet

- 점과 군집은 나중에 더 압축된 결과면으로 나올 수 있다.
- 하지만 지금 공간의 본체는 아직 거기에 있지 않다.
- 현재 더 본질적인 것은:
  - 입력이 들어오는 일
  - 1차 흔적이 남는 일
  - 1.5차 packet이 묶이는 일
  - 2차가 다시 읽는 일
  - 연결 / hold / residue / weak / fallback 상태가 생기는 일
  - 운영자가 그 과정을 따라가며 다시 읽는 일
  이다.

## 3. what the current space actually is

- 현재 공간은 결과 지도라기보다
  - 원문
  - 1차 값
  - 1.5차 memory packet
  - 2차 재독해 값
  - hold / residue / blocker / 연결 흔적
  을 카드처럼 따라가는 과정면이다.

즉 지금 공간은:

> 원문-값-연결-재독해를 운영자가 따라가며 연결의 의미를 다시 읽는 운용화면이다.

## 4. why card/source/value/link tracking comes first

- 지금은 graph를 예쁘게 펼치는 것보다
  - 어떤 원문에서
  - 어떤 1차 흔적이 나왔고
  - 그것이 어떤 packet으로 묶였고
  - 2차에서 무엇이 weak/fallback/hold로 남았는지
  를 읽는 것이 더 중요하다.

- 따라서 현재 우선 표면은:
  - source card
  - first-order trace
  - probe packet
  - second-order rereading note
  - hold / residue / blocker badge
  같은 운용 추적 카드면이어야 한다.

## 5. `washtank/src/officeout.jsx` 비유 재서술

- reference의 `officeout.jsx` 비유를 현재 공간에 맞게 다시 읽으면,
  지금 필요한 것은 완성된 wall map보다
  책상 위에 놓인 원문과 메모와 라벨과 보류 표시를 보며
  운영자가 손으로 따라가는 작업면에 가깝다.
- 즉 현재 공간은 showroom이 아니라
  **작동 중인 operating desk / rereading console** 에 더 가깝다.

## 6. operating principles for not misreading the space

- 현재 공간을 결과 cluster처럼 읽지 않는다.
- current value를 final meaning처럼 읽지 않는다.
- hold / weak / fallback을 미달 표시로 읽지 않는다.
- 원문과 값 사이 추적 가능성이 현재 graph density보다 더 중요하다고 본다.
- 지금 표면의 목표는 “무엇이 정답인가”가 아니라 “무엇이 어떻게 자라고 있는가”를 따라가게 하는 것이다.

## 7. one-line summary

> 현재 `vectorfl_replica` 공간은 점/군집의 결과면이 아니라, 원문에서 1차 흔적과 2차 재독해가 생성되고 연결되는 과정을 운영자가 따라가며 다시 읽는 운용화면이다.
