# second-order memory asset repositioning note v1

## 1. purpose

- 이번 노트의 목적은 recent second-order 자산들을 실패 목록이 아니라 기억 자산으로 다시 배치하는 것이다.

## 3. key repositioning

- weak / fallback / partial 값은 버릴 중간값이 아니다.
- 그것들은 나중에 directness, recurrence, carryover 감소를 비교할 수 있게 해 주는 future comparison memory다.
- hold는 실패가 아니라 열림을 남겨 두는 상태다.
- blocker는 적이 아니라 premature closure point다.

## 4. one-line summary

> recent second-order 자산들은 실패 기록이 아니라, 현재 계절의 생육 조건·실패면·보류 이유·반복 기억·다음 계절 진입 조건을 함께 보존하는 기억 자산이다.
