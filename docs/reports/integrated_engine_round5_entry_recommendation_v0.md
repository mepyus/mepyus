## 1. can round 5 start?

Yes.

- Round 4 found no central gravity failure, read-map drift, support-layer promotion, object-class collapse, or governance/runtime-truth drift.

## 2. allowed scope

Round 5 should be limited to:

- boundary emphasis refinement

- formal render-field inventory note per surface or per panel

## 3. not allowed

Round 5 should not include:

- scaffold semantic relayout
- panel read mapping changes
- manifest shape changes
- shared components
- runtime binding or live manifest truth
- selected-object behavior
- extension promotion
- watcher / supervisor / bridge / governance authority

If round 5 is deferred, no urgent blocker must be solved first.
