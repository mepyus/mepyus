## Extension Judgment: Position Value Layer

The term `Position Value Layer` is not explicitly present in the nine documents.

Codex introduced it as an extension to satisfy a repeated requirement from the nine documents:

```text
small anchors must carry line / axis / camera / lens and stop/continue/return criteria without replaying the whole space.
```

Position IDs are therefore a compression layer for small anchors.

They must remain:

- seed candidate
- compact coordinate layer
- not ontology
- not schema
- not registry
- not baseline
- not automation
