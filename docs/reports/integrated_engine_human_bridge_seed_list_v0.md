Date: 2026-04-15

## 0. verdict

PASS_WITH_NOTE

This document records bridge seeds only.

## 1. purpose

Some internal integrated-engine phrases resist direct simplification because they carry route, authority, state, boundary, or support meaning.

This seed list records what later human-facing bridge work must preserve. It intentionally stops before writing final translations.

## 2. seed list

| internal term or phrase | why it resists flattening | what a human-facing bridge must preserve | what should never be lost |
|---|---|---|---|
| `request packet` | It is not raw intent or a generic task card. | It carries shaped purpose, directionality, anchor references, related objects, and requested next action. | Anti-bypass: request must not imply direct raw user-to-engine execution. |
| `return packet` | It sounds like completion, but it is not validated completion. | It is engine-side processing material prepared for validation. | Engine output is not final meaning or final product completion. |
| `reflux` | It is unfamiliar and can sound like rollback or failure. | It routes maturation-worthy material back toward space for reread and growth. | Reflux is preservation with reason, not discard, archive, or error recovery. |
| `anchor drift` | It can sound like a passive mismatch label. | It is a route-braking signal that can stop user decision and trigger reprocess. | Anchor mismatch has operational force. |
| `return validation` | It can be mistaken for engine self-check. | VectorFL validates return material before user decision, reflux, or reprocess. | Validation ownership stays separate from execution. |
| `current_loop_state` | It can sound like the whole workflow history. | It locates the current active loop position. | Full movement history requires packets and connection records. |
| `held_from_closure_reason` | It is an internal state phrase, not natural public language. | It explains why the loop stayed open instead of closing. | Non-closure is intentional when a reason is recorded. |
| `rewind_reason` | It can sound like confusion or undo. | It explains why the route moved back to reprocess or recheck. | Rewind can be structured correction, not failure. |
| `not promoted / watch keep` | It can sound like rejection or passive backlog. | The candidate remains visible but does not open patch planning. | Watch state is an active operating state with re-entry conditions. |
| `support reread recovery` | It can sound like forcing the reader to hunt. | Some meanings recover when central panel, packet, support panel, and connection record are read in order. | Recovery does not equal runtime trace UI or selected-object behavior. |
| `fixture-scope limitation` | It can sound like a broken scaffold. | The current direct read mapping is first-fixture centered; other samples are checked manually through panel-role grammar. | Fixture scope is not automatically wording confusion or structural failure. |
| `core-support trace boundary` | It can sound like missing trace UI. | Compact trace can support current manual reading without becoming a full timeline. | Trace support is not live event truth or selected-object behavior. |
| `proposal-only / needs Codex translation` | It can sound like weak or delayed work. | Proposal material must be filtered through the current baseline before core use. | Proposal status is an authority boundary, not a quality insult. |
| `workspace ownership` | It can sound like file bureaucracy. | Gemini writes proposal material under `gemini/`; Codex writes canonical reports/scaffolds only when scoped. | File location protects baseline authority and collision prevention. |
| `design clay` | It can sound ready to implement because it may be visually strong. | It is raw design material that may be translated, held, or rejected. | Visual strength does not equal baseline fit. |
| `central panel gravity` | It can sound like design preference. | Each surface has a protected center: user operating, VectorFL maturation, engine execution. | Support panels and visual tokens must not replace the central role. |
| `support layer stays subordinate` | It can sound like support is unimportant. | Support panels explain route, criteria, evidence, or context without becoming the body. | Support can have force without being promoted to core. |
| `collision stop condition` | It can sound procedural. | Parallel agent work must stop when it would require core drift or unauthorized edits. | Safety boundary must not be softened into optional caution. |

## 3. bridge caution

Later bridge work should not start by replacing these terms one by one.

It should first preserve:

- route direction and route reason
- ownership and authority boundary
- hold/watch state
- operational brake or reprocess condition
- support-vs-core distinction
- current use-mode limits

Only after those are protected should user-facing phrasing be attempted.
