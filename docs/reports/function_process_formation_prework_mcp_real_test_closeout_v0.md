## 5. Preserved reusable lens
### Resource
*   **project reading:** Space-side asset / context / record / material.
*   **useful for:** Identifying what should be exposed as context or reference to a worker session.
*   **caution:** Not every project record should be exposed as a formal resource.

### Tool
*   **project reading:** Execution-side action / skill / operation / API call.
*   **useful for:** Distinguishing bounded action from read-only material.
*   **caution:** Not every executable capability should be attached to the system.

### Resource / Tool Distinction
*   This distinction is a **comparison lens** to be used during future prework rounds. It is not an adoption decision or a required system ontology.
