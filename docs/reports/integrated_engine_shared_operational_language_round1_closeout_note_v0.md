## 2. what was corrected

수정된 방향:

- 3면 언어를 인간용 최종 요약으로 수렴시키지 않는다.
- 3면 언어를 내부에만 쌓아두지도 않는다.
- 내부 언어에서 인간 가독 line을 뽑고, 반복 connection을 보고, emerging axis를 찾는다.
- 그 axis에서 여러 주체가 같이 쓸 수 있는 shared operational language를 만든다.

Shared operational language는:

- user-only language가 아니다.
- engine language replacement가 아니다.
- final glossary가 아니다.
- surface별 노출 밀도를 조절하는 운영 언어다.

## 3. strongest shared grammar candidates

현재 가장 강한 후보:

1. reasoned route grammar
   - `request / return / reflux`
   - `follow-up / reprocess / rewind`
   - source, target, purpose, reason, validation status가 route를 만든다.

2. scoped authority grammar
   - `proposal-only / needs Codex translation`
   - `workspace ownership`
   - user package-opening authority
   - authority는 surface/workspace/package scope에 의해 결정된다.

3. validation brake grammar
   - `return validation`
   - `anchor drift`
   - `collision stop`
   - route는 validation/anchor/boundary에서 멈추거나 되감을 수 있다.

4. active non-action grammar
   - `hold`
   - `watch keep`
   - `not promoted`
   - 아무것도 하지 않는 것이 아니라, 보존하면서 action을 열지 않는 상태다.

5. support reread grammar
   - `support reread recovery`
   - `current_loop_state`
   - connection records / support panels
   - 첫 읽기의 얇음과 구조 실패를 구분한다.

## 4. still thin areas

아직 얇은 축:

- `workspace ownership`
  - shared language로 올라왔지만 folder owner로 납작해질 위험이 계속 크다.

- `carry-forward`
  - preservation without commitment로 읽혀야 하지만 future roadmap으로 오해되기 쉽다.

- `reject / conflict`
  - scoped current-baseline conflict로 읽혀야 하지만 global badness로 들릴 수 있다.

- user-facing fixed interface
  - 아직 final shape가 없다.
  - line / connection / axis에서 도출되어야 하며 외부 template으로 만들면 안 된다.

- actor-specific usage
  - User, VectorFL, Engine-side operators, Codex, Gemini가 실제로 같은 shared language를 어떻게 다르게 쓰는지 trial이 더 필요하다.

## 5. surface exposure summary

Surface별 노출 요약:

| surface | exposure rule |
|---|---|
| engine surface | processing / execution / return material internal language direct exposure 허용. 단 validation authority 흡수 금지. |
| VectorFL surface | shared grammar, anchor, validation, maturation, reflux, line/connection/axis mediation 중심. |
| user surface | human-readable shared grammar 중심. 사용자가 operation/decision할 수 있는 만큼만 internal term 노출. |

핵심:

- shared language는 user-only language가 아니다.
- shared language는 3면 내부 언어를 덮어쓰지 않는다.
- shared language는 actor별 노출 밀도를 조절하는 운영층이다.
