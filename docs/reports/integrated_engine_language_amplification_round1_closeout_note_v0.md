## 3. newly visible grammar axes

### route as reasoned movement

Routes are not simple flow arrows. They carry packet kind, source, target, purpose, anchor context, validation status, and next action.

Strong repeated examples:

- request is not raw intent
- return is not completion
- reflux is not rollback
- reprocess is not accidental retry

### authority as scoped boundary

Authority is distributed by surface, workspace, and promotion gate.

Strong repeated examples:

- engine processes but does not validate final meaning
- VectorFL validates but does not execute engine work
- Gemini proposes but does not enter core directly
- Codex translates and records canonically only when scoped
- user decides promotion

### hold/watch as active state

Hold and watch are not weak forms of rejection.

Strong repeated examples:

- `not promoted`
- `watch keep`
- `stop-and-use / use observation`
- `build mode closed`
- `patch planning closed`

### validation as brake and route selector

Validation is not only a check after work. It can stop, reroute, reprocess, or preserve.

Strong repeated examples:

- return validation before user decision
- anchor drift as operational brake
- held-from-closure and rewind reasons

### support reread as recovery mechanism

The current baseline accepts some first-pass thinness if the intended reading recovers through panel-role grammar, packets, support panels, and connection records.

Strong repeated examples:

- S2 recoverable first-pass ambiguity
- S3 anchor brake readable through connection record
- current loop state plus connection records for route reconstruction

### bridge-before-flatten

Human-facing language should not simplify first. It must first preserve route, authority, state, boundary, and support relationships.

Strong repeated examples:

- `reflux`
- `anchor drift`
- `return validation`
- `proposal-only / needs Codex translation`
- `workspace ownership`
