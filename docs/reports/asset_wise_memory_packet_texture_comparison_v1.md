## 4. current pattern

- overcompressed라고 전부 같은 overcompressed는 아니다.
- `knowledge_editing_youtube`는 flat/closure-heavy 쪽이고,
- `gary_tan_brain`은 compressed지만 meaning density와 emergence가 조금 남아 있는 breathing 쪽이다.
- `openai_02_11`는 overcompressed가 아니어도 emergence가 약할 수 있다는 비교 기준이다.

## 5. one-line summary

> 최근 자산들은 “잘 읽힘/안 읽힘”으로 나뉘는 것이 아니라, `moderately open`, `structured-open but low-emergence`, `overcompressed and closure-heavy`, `overcompressed but breathing` 같은 질감 차이로 읽는 편이 정확하다.
