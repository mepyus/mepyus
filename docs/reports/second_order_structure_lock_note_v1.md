# second-order structure lock note v1

## 1. purpose

- 이 문서의 목적은 앞으로 2차 판독 계층에서 무엇은 고정층으로 두고 무엇은 실험층으로 둘지 명확히 잠그는 것이다.
- 즉 scaffold reduction 실험이 바닥 구조를 흔들지 않게 하는 `structure lock note`다.

## 2. fixed layers

- 1차 값은 센서값이라는 관점
- 2차 값은 재독해 / 보정 / 축적층이라는 관점
- question opening / relation movement / residue priority shift를 reusable attitude로 먼저 관찰하는 원칙
- object lift hold 원칙
- condition table / scaffold dependency log / failure accumulation을 계속 축적하는 구조
- candidate / hold / collect_only 중심 운영 원칙

## 3. experimental layers

- segmentation adapter 또는 segmentation support
- pointer stabilization 보조 방식
- heading-independent role probe
- context unit ref anchoring 보조 규칙
- naming suppression이 아니라 naming hold 조건 강화 방식
- report wording scaffold 정리 방식

## 4. what this lock means

- 지금 바꿀 수 있는 것은 `기관`이다.
- 지금 바꾸면 안 되는 것은 `태도`와 `운영 원칙`이다.
- 즉 실험은 아래를 바꾸기 위한 것이 아니다.
  - object lift hold
  - candidate 중심 운영
  - attitude vs institution split
  - failure accumulation as evidence

## 5. current read

- 2차 판독 계층은 지금 완성형이 아니다.
- 하지만 완성형이 아니기 때문에 더더욱:
  - 바닥 원칙은 고정하고
  - segmentation / pointer / heading 같은 기관만 최소 실험으로 조정해야 한다.

## 6. one-line summary

> 앞으로 2차 판독에서는 reusable attitude와 운영 원칙은 고정층으로 잠그고, segmentation / pointer / heading 같은 기관만 최소 실험층으로 제한해 다룬다.
