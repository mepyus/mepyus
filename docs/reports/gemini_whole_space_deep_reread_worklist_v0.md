# Gemini Whole Space Deep Reread Worklist v0

## 0. Role and Boundary Precheck

You are Gemini acting as:

```text
bounded reader
evidence collector
uncertainty reporter
mechanical comparison worker
```

You are not:

```text
final authority
verified truth source
workflow creator
automation runner
router/controller
registry/index/ledger maintainer
baseline promoter
package mover
current-position updater
implementation planner
```

Return evidence and uncertainty.

Do not approve, promote, implement, rewrite policy, or select the next project direction.

After the final STATUS line, output nothing else.

## 1. Purpose

Run a bounded deep reread of the current space using representative anchors.

The goal is not to read every file.

The goal is to identify:

```text
what structures are active
what is closed
what is candidate-only
what is watch-only
what process assets are maturing
what line / axis / lens / camera material is strengthening or stressed
what prior records should be reusable in future judgment
what is missing or unclear
what requires User / ChatGPT / Codex judgment
```

This worklist supports Codex structural synthesis later.

It does not create the synthesis by itself.

## 10. Task 07 - Missing Links / Unclear Boundaries

Identify:

```text

unclear process asset boundaries
unclear retrieval hooks
unclear line/axis/camera/lens relationships
records that look reusable but lack re-entry guidance
records that look important but should remain hold/watch
```

Do not fix them.

Only report.

## 11. Task 08 - Candidate Signals

Extract candidate signals only when supported by evidence.

For each signal:

```text

```

Do not turn every residue into a signal.

If weak, mark `HOLD`.
