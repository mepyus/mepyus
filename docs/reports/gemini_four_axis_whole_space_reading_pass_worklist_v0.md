# Gemini Instruction - Four-Axis Whole-Space Reading Pass v0

## 0. Mode

This is a bounded whole-space reading pass using the Four Maturation Axes.

Do not read new external materials.
Do not search for new sources.
Do not implement anything.
Do not create automation.
Do not create runtime scripts.
Do not create registry, index, ledger, router, controller, formal schema, or official workflow.
Do not update current-position.
Do not promote anything to baseline.
Do not attach any tool/API/function/repo.
Do not create ontology.
Do not start a new pipeline.
Do not treat your output as verified truth or final authority.

Your output is worker evidence only.

The purpose is to read the space, not to read another material.

## 1. Core Distinction

This is not material reading.

```text
Material reading asks:
What does this source say?

Space reading asks:
What does the current space reveal when read through these axes?
```

Use the Four Maturation Axes as orientation cameras, not as laws.

The four axes are:

```text
1. Cognitive Harness & Containment
2. Sovereign Decoupling
3. Layered Maturation & Reuse
4. Structural Affordance & Communication
```

These are:

```text
orientation candidate / re-entry map
not baseline
not ontology
not workflow
not architecture
not current-position update
```


