# Intake Bundle Examples Round 1 v0

## Summary

Created two minimal manual intake bundle examples:

- one successful external result capture
- one failed external result capture

## Sufficiency Judgment

The current intake bundle convention feels sufficient for phase-1 manual capture.

It captures source, intent, references, artifacts, summary, risks, next move, and translation notes without becoming a package record.

## Successful And Failed Capture Read

Both successful and failed captures read naturally.

The successful example records usable source evidence.

The failed example records why intake should wait until the missing artifact is resolved.

## Awkward Or Missing Sections

No new section is needed yet.

`outputs_artifacts` is slightly broad, but it is useful because phase 1 prefers pointers over copied raw logs.

Next package: define the minimal manual handoff rule from intake bundle to intake package, still spec-only and without conversion logic.
