# Topic: Knowledge Graph, Semantic Layer, and Ontology Evolution

- **Mode:** Web research first, external view first.
- **Scope:** Read-only.

## 1. Why Round 003
Round 002 solved the "how to store" question; now we look at "how to structure without suffocation." We need to avoid the "Schema-First" trap while benefiting from semantically rich connections.

## 2. Findings
- **Folksonomy to Ontology:** Start with unstructured tags (Folksonomy), transition to hierarchies only when patterns mature.
- **Semantic Layer:** Decoupling the data storage from the "Lens" (View).
- **GraphRAG:** Using graphs to guide retrieval relevance, rather than as a strict database schema.

## 3. Risks
- Premature schema locking destroys the "Reverse Ontology" and makes the space rigid.
