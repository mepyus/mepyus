## 5. required special carry-forward items

### team / role / ownership / approval-alignment

Status: extension later.

This can support user-surface distribution and decision follow-through, but it must not precede request / return / reflux visibility or turn the user surface into a team console.

### validation team / translation team / research-assist structure

Status: extension later.

This can support VectorFL validation work, but it must stay outside the core mediation / maturation panels unless a tool-layer boundary prevents staffing or research assistance from becoming authority.

### watcher / supervisor / bridge

Status: extension later.

These remain optional tool-layer candidates only. They cannot appear as core panels, live truth sources, command desks, or governance surfaces.

### line atlas / richer axis browser / inspection depth

Status: extension later.

These are promising for VectorFL usability, but they must remain support selection / side inspection until `maturation_canvas_panel` has a protected selected-object contract.
