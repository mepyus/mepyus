## 5. Why This Pipeline Exists

The space has accumulated many records:

```text
current-position entries
next-chat summaries
role references
operating model candidates
line / axis / lens / camera reports
external-material intake records
Gemini evidence records
mistake-memory
package preflight notes
function/process formation prework records
integrated-engine and CLI-side reports
long-arc reread maps
```

The problem:

```text
If records are only stored, they become archive.
If the reread is unbounded, it becomes token drain.
If useful signals are promoted automatically, the space becomes unsafe.
```

The pipeline solves the middle problem:

```text
how to reread enough of the whole space to detect structure,
while keeping the reread bounded, evidence-based, and User-gated.
```

## 6. Pipeline Stages

| Stage | Name | Owner | Input | Output | Stop / Guardrail |
|---|---|---|---|---|---|
| 0 | User Purpose Gate | User / ChatGPT | request to reread whole space | bounded reread purpose | stop if no User purpose |
| 1 | Codex Structure Setup | Codex | setup docs and closeouts | pipeline setup + Gemini worklist | no Gemini autonomous run, no automation |
| 2 | Gemini Evidence Inventory | Gemini when User relays worklist | bounded file list | evidence table by stratum | no broad search, no authority decisions |
| 3 | Gemini Structural Observation Pass | Gemini | evidence inventory | active/closed/candidate/watch observations | evidence only, not verified truth |
| 4 | Gemini Lens / Camera / Line-Axis Pass | Gemini | bounded line/lens/camera records | fit/stress/gap/uncertainty table | lens not law, camera not truth |
| 5 | Gemini Mistake / Drift / Missing-Structure Pass | Gemini | prior observations | mistake risks and missing links | report only, no patching |
| 6 | Codex Structural Synthesis | Codex after User returns Gemini result | Gemini evidence bundle | synthesis / process assets / watch carry-forward | no final authority, no current-position update by implication |
| 7 | ChatGPT / User Judgment | ChatGPT / User | Codex synthesis | accept / hold / ask another read / stop | no hidden movement |
| 8 | Recovery | Codex after User decision | User decision | process-memory-light / candidate reference / closeout / current-position only if required | no automatic registry/index/ledger |
