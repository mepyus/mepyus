# VectorFL Paper Proper Mock Surface Note v0

## purpose

이 문서는 현재 canonical pilot seam을
`VectorFL Paper proper` 관점에서
어떻게 다시 보여주기 시작했는지 기록한다.

## what changed

새 proper mock surface는
artifact 묶음보다 먼저 아래 두 개를 전면에 올린다.

- `Operating Board`
- `Cell / Worker Panel`

즉 이제 첫 화면은
무엇이 생성됐는지보다
지금 무엇을 증명 중인지,
어떤 cell과 cli가 현재 움직이는지,
어디에 감독 판단이 필요한지를 먼저 말한다.

## why this matters

이 변화는 단순 layout 수정이 아니다.

이전 pilot은 seam 검증에는 유용했지만
사용자가 읽기에는 여전히 manifest pile처럼 보일 위험이 있었다.

proper mock은
앞서 잠근 page tree와 section contract를 따라
`supervisor entrypoint`와 `contract-driven operating panel`
을 먼저 보이게 만든다.

## what it still is not

- 아직 real proper runtime은 아니다
- 아직 actual exported host record rerun은 안 닫혔다
- 아직 case detail / inspector / trace-governance proper pages 전체를 만들지는 않았다

즉 이것은
proper 구조로의 첫 화면 승격 mock이다.

## next use

다음 단계에서 이 mock을 기준으로

- operating board
- case detail
- cell / worker panel
- trace / governance

를 차례로 더 concrete한 proper surface로 내린다.
