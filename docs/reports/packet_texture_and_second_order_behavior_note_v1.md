# packet_texture_and_second_order_behavior_note_v1

## 1. purpose

- 이번 문서의 목적은 memory packet 질감과 2차 기관 반응 사이의 관계를 정리하는 것이다.

## 2. current observations

### A. question-inducing emergence
- `moderately open / dialogue-supportive`
  - emergence가 가장 자연스럽게 뜬다
- `overcompressed but breathing`
  - minimal non-zero emergence가 가능하다
- `overcompressed and closure-heavy`
  - emergence가 거의 `0`으로 남는다
- `structured-open but low-emergence`
  - granularity가 건강해도 emergence는 약할 수 있다

### B. context unit behavior
- packet이 closure-heavy일수록
  - context unit은 비거나
  - scaffold carryover 위 이름만 남고
  - ref는 empty / fallback 쪽으로 기울기 쉽다
- packet이 breathing할수록
  - pass reaction은 살아나지만
  - 아직도 prepared scaffold가 남으면 context unit institution은 여전히 uneven하다

### C. role-like reading
- `youtube_03_22`
  - role-like reading이 가장 자연스럽다
- `openai_02_11`
  - weak_medium + fallback grounded
- `knowledge_editing_youtube`
  - weak + empty_ref
- `gary_tan_brain`
  - weak + empty_ref, but question emergence가 있어 전체 질감은 조금 더 열린다

## 3. packet texture vs scaffold carryover

- 이 둘은 같지 않다.
- packet 질감은
  - 압축도
  - 추적성
  - emergence
  - grounding
  의 결합 상태다.
- scaffold carryover는
  - 2차 기관이 기존 unit/role/wording을 새 자산에 재투사하는 문제다.

즉:
- overcompressed packet이 carryover를 악화시키는 경우는 많다.
- 하지만 carryover는 packet 질감과 별개로 2차 기관 내부 prepared scaffold 문제이기도 하다.

## 4. operator implication

- 운영자는 앞으로
  - packet이 과압축되었는가
  - 그래도 숨을 쉬는가
  - emergence가 있는가
  - carryover가 packet 탓인지 2차 기관 탓인지
  를 분리해서 봐야 한다.

## 5. one-line summary

> 2차 반응의 약함은 모두 같은 원인이 아니다. 어떤 것은 packet 질감의 문제이고, 어떤 것은 2차 기관 내부 scaffold carryover 문제다. 이 둘을 분리해서 읽는 것이 현재 비교 기억 자산의 핵심 가치다.
