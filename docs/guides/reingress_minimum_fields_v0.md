# Reingress Minimum Fields v0

## Execution

Required:

- original request
- interpreted goal
- searched asset summary
- space position summary
- Codex position summary
- chosen mode
- final return summary
- unresolved notes
- future probe note

Recommended:

- new line or axis candidate
- artifact refs
- validation booleans

Do not store:

- raw full file dumps unless necessary;
- UI implementation details for Phase 1;
- unsupported conclusions without evidence refs.

## Interpretation

Reingress is a trace of how the space changed by being asked. It should be small enough to read later and structured enough to become search/evidence material.

## Validation

- record can be read without the full conversation.
- record points back to artifacts.
- unresolved remains visible.
