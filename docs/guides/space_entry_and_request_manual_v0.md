## Short-Question Working Rule

For normal product-like requests, the user only needs:

- target
- purpose

The system should then decide:

- model-only
- space-first
- external-first
- space-plus-external
- answer-plus-reinjection

## Stop Rule

If a stable guide already answers where to go next, stop reading and do the bounded work.

Do not keep climbing into deeper docs unless:

- the current guide is not enough
- the target is unresolved
- a boundary note is explicitly needed

## One-Line Summary

Start from the job-to-entry path, not from blind repo search.
