# Split Unit Examples For Line Seed v0

## Example A — Over-Thin Heading Unit

Artifact:

- `app/work/observer_ingest_min/generated/split_units_raw_intake_gap_analysis_before_middle_layer_fix_v1_20260409_184529.json`

Observed unit:

- `unit_001`
- excerpt: `# raw intake gap analysis before middle-layer fix`

Why it is weak:

- bounded and traceable;
- but role is only title/context;
- no line pressure survives by itself.

Use:

- keep as context unit;
- do not treat as stand-alone line seed.

## Example B — Thick Heading Block

Observed unit:

- `unit_002`

Why it is mixed:

- stronger than a title-only unit;
- but likely mixes context, comparison, and connective work.

Use:

- better as part of a line-seed bundle than as a single clean seed.

## Example C — Transcript Dust Problem

Artifact family:

- transcript preprocess comparison and regroup outputs

Why it matters:

- the preprocessor exists because raw transcript dust units are too fine;
- line seed would not survive if each subtitle-like row stays isolated.

Use:

- keep the original split trace;
- grow meaning through regroup or bundle, not by pretending the dust was enough.
