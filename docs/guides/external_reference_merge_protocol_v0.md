# External Reference Merge Protocol v0

## Purpose

This protocol defines when separate external references should be merged into one bounded support note.

The goal is not to create a stronger doctrine.
The goal is to create a more reusable reread cluster when multiple sources are complementary.

## Core Rule

Do not merge external references just because they are vaguely related.

Merge only when the result improves reuse more than it increases blur.

## Merge Triggers

A merge is justified when at least one of these is true:

### 1. complementarity

Different sources supply different missing layers of the same operating pressure.

Typical pattern:

- broad rationale
- concrete runtime surface
- concrete operator control

### 2. repeated operating tension

Multiple sources reinforce the same bounded tension, such as:

- plan before run
- bounded surface over unrestricted freedom
- reviewable adjustment over blanket change

### 3. downstream reread value

The merged note would be easier to reuse later for:

- tool boundary judgment
- worker-style execution judgment
- attachability reread
- output/context budget judgment

## Do Not Merge When

Do not merge when:

- the sources are only topically similar
- one source dominates and the others add little
- the merge would flatten important subtype differences
- the result would read like doctrine instead of bounded support

## Required Merge Shape

A merged note should make each source role explicit:

1. what source A contributes
2. what source B contributes
3. what source C contributes
4. what coherence the merge adds
5. what the merge still does not justify

## Required Output Close

A merge observation should always state:

- current position
- can use now
- should not use yet

## Promotion Guard

Merging does not justify:

- promotion
- new axis
- operating rule lock
- architecture import

Merged notes remain:

- bounded external support clusters
- reread aids
- operating reference material

## One-Line Summary

Merge external references only when the merge adds bounded reuse value through complementarity or repeated operating tension.
