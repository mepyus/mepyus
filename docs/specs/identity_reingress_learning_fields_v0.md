# Identity Reingress Learning Fields v0

## Purpose

Reingress should preserve what identity anchors worked and where identity remained inferred. This helps future comparison runs prefer artifacts that can describe their own role and lineage.

## Fields

- `useful_identity_modes`
- `family_key_summary`
- `weak_identity_areas`
- `generated_from_chain_summary`
- `next_identity_probe_hint`
- `reusable_identity_groups`
- `identity_risk_summary`

## Interpretation

Comparison results are incomplete without identity learning. The next run needs to know why an artifact was read as a member of a family, not just what changed inside it.

Weak identity areas are useful material. They point to artifacts that need better emitted anchors or more careful manual support.

## Validation

- Reingress must include identity learning fields.
- Reusable identity groups must be visible.
- Weak identity must be preserved honestly.
