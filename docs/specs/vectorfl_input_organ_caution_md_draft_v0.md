# Input Organ CAUTION.md Draft v0

## caution purpose

Input organ의 caution 규칙은  
입력 재료가 약하거나 섞여 있더라도 그것을 지워서 깔끔하게 만드는 대신,  
약함을 다음 기관까지 carry하게 하는 데 목적이 있다.

## stop / hold conditions

- source identity still unclear
- context attachment remains partial
- structure-aware split failed
- mixed material cannot be confidently flattened

## preserve-first rules

- fallback used state는 숨기지 않는다
- weak classification은 weak로 남긴다
- provenance/origin을 잃지 않는다
- unresolved ingest는 residue_only로도 남길 수 있다

## avoid

- final line naming
- definitive case meaning
- safe-to-close wording

## final sentence

Input organ은 깔끔한 입력만 넘기는 기관이 아니라, 약함과 fallback을 지운 채 넘기지 않도록 보수적으로 멈추고 carry하는 기관이다.
