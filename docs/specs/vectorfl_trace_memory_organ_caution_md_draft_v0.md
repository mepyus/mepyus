# Trace Memory Organ CAUTION.md Draft v0

## caution purpose

Trace/memory organ의 caution 규칙은  
trace를 generic activity feed로 약화시키거나, residue를 완료 메모처럼 다듬어 버리는 것을 막는 데 목적이 있다.

## stop / hold conditions

- trace summary is replacing canonical source
- residue is being flattened into success note
- reentry hint is dropped
- append-only order is lost

## preserve-first rules

- residue는 residue로 남긴다
- reentry는 next reread cue로 남긴다
- decision anchor를 current-reading과 끊지 않는다
- append-only ordering을 유지한다

## avoid

- polished timeline storytelling
- success-only history
- trace without residue or caution

## final sentence

Trace/memory organ은 보기 좋은 history를 만드는 기관이 아니라, 다음 읽기와 handoff가 더 정확해지도록 보존 우선 규칙을 강하게 지키는 기관이다.
