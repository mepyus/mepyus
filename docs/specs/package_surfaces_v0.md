# Package Surfaces v0

## Purpose

This spec names the phase 1 package surfaces without designing UI or automation.

## Package Surface Meaning

A package surface is a folder-level landing area for a package kind inside our space.

It is a structural boundary only.

## Phase 1 Surfaces

- `space/packages/intake/`
- `space/packages/digestion/`
- `space/packages/review/`
- `space/packages/memory/`

## Responsibilities

The surfaces separate package intent before deeper processing exists.

They do not imply runtime behavior, UI routes, hooks, workers, or schema validation.

## Boundary

This version only reserves names and responsibilities for phase 1 package kinds.
