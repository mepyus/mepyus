# Line State Organ RETURN.md Draft v0

## return purpose

Line/state organ의 반환은  
새로운 의미망이 생길 수 있는지, 기존 line이 더 두꺼워졌는지,
아니면 아직 carry/candidate로만 남아야 하는지를 다음 기관이 읽을 수 있게 넘기는 것이다.

## minimum return blocks

### 1. line seed proposal

- 새 line candidate 또는 line family hint

### 2. thickening / reuse / carry note

- new generation인지
- thickening인지
- reuse인지
- carry인지

### 3. evidence refs

- source/intake refs
- current surface refs
- trace/residue refs

### 4. caution note

- candidate-only
- non-line dominant
- weak recurrence

## preferred wording

- "candidate line ..."
- "treat as thickening ..."
- "carry existing line ..."
- "reuse appears stronger than generation ..."

## avoid wording

- "new stable line" without evidence
- "fully formed line"
- "promote now"

## final sentence

Line/state organ의 반환은 line을 선언하는 선포문이 아니라,  
line/state 형성 가능성을 evidence와 caution과 함께 다음 기관에 넘기는 formation-aware return이어야 한다.
