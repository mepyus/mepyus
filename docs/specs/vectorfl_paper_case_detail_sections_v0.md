# VectorFL Paper Case Detail Sections v0

## purpose

이 문서는 `Case Detail`이
단순 상세 페이지가 아니라
`VectorFL Paper proper`의 reading center로 작동하려면
무엇을 먼저 보여줘야 하는지 섹션 단위로 잠근다.

---

## page role

`Case Detail`은 아래 질문에 답해야 한다.

- 지금 어떤 case를 읽는 중인가
- 어떤 source와 pressure가 이 case를 만들었는가
- 어떤 line seed가 생겼는가
- 무엇이 stable하고 무엇이 unclear한가
- 어떤 evidence bundle이 왜 붙는가
- 무엇이 아직 unread boundary로 남는가
- 다음 action은 무엇인가

즉 이 페이지는
case의 `reading organ`이어야 한다.

---

## section order

### 1. case header

- case purpose
- current stage
- current judgment
- why this case matters now

### 2. source read

- reread materials
- scenario pressure
- source basis
- what was actually read

### 3. line seeds

- line seed list
- repeated pressures
- misunderstanding corrections
- next questions

### 4. evidence bundles

- linked bundle list
- why each bundle is attached
- what each bundle lets us confidently say

### 5. human translation

- supervisor-readable summary
- work-facing language
- why this is not just a summary

### 6. missing and not yet read

- unclear points
- unread boundary
- realism gap
- what still resists closure

### 7. next action

- next cell
- why this handoff happens now
- what inputs should move forward

---

## global page rules

### rule 1

source and line must appear before action.

### rule 2

stable / unclear split must stay visible.

### rule 3

human translation must not hide unread boundary.

### rule 4

bundle attachment must explain why it is here.

### rule 5

the page must read as one loop stage, not as a file inventory.

---

## one-line lock

`Case Detail`은
source, line seed, evidence, human translation, unread boundary,
and next action이 한 흐름으로 읽히는
VectorFL Paper proper의 중심 reading page여야 한다.
