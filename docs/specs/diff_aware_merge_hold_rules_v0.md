# Diff Aware Merge Hold Rules v0

## Execution

Rules:

- Trivial field changes alone should not justify strong diff.
- Salient status/mode/evidence-depth/chosen-mode changes strengthen diff.
- Before/after evidence must be visible for a diff claim.
- Authority conflict remains separate from ordinary diff tension.
- If diff evidence is strong, `diff` can be more honest than `merge`.

## Interpretation

Not every changed path matters. Diff salience prevents noise from becoming judgment while still preserving meaningful operational changes.

## Validation

- Diff evidence affects merge risk.
- Hold remains narrow.
