# VectorFL Page Semi-Live Route Set Lock v0

이 문서는 `semi-live current-reading`을  
다른 primary surfaces까지 확장한 `semi-live route set`의 기준을 잠근다.

목적은 한 면만 runtime-connected인 상태에 머무르지 않고,
같은 runtime bridge를 `Cases / Queue`, `Inputs / Intake`, `History / Trace`, `Programs / Connections`
에도 일관되게 적용해 개인용 page shell 전체를 더 실제 상태에 가깝게 만드는 것이다.

## 1. Core Sentence

Semi-live route set은  
같은 runtime source를 번역해 다섯 primary surface 모두를 current-reading-first 의미축 위에서 열 수 있게 만든 shell 세트다.

## 2. Required Rule

- 같은 runtime source를 쓴다
- surface별 primary meaning은 유지한다
- current-reading semantic center는 유지한다
- contextual organ detail도 유지한다

## 3. What Must Not Drift

- runtime raw surface가 각 page의 의미를 대신하는 것
- queue/history/programs가 generic dashboard로 drift하는 것
- surface별 semantic difference가 사라지는 것

## 4. Final Lock Sentence

현재 기준은 다음 문장으로 잠근다.

`VectorFL Page의 semi-live route set은 current_phase, preflight_last_decision, engine_state_latest를 공통 source로 삼아 다섯 primary surface를 모두 갱신하되, 각 surface의 의미 차이와 current-reading-first 중심축을 유지하는 방향으로만 확장해야 한다.`
