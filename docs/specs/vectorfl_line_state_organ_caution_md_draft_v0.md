# Line State Organ CAUTION.md Draft v0

## caution purpose

Line/state organ의 caution 규칙은  
candidate, thickening, reuse, carry를 과장해 모두 `새 line 생성`처럼 보이게 만드는 것을 막는 데 목적이 있다.

## stop / hold conditions

- evidence too weak for line seed
- existing line reuse is more plausible than new generation
- non-line unit dominates the case
- residue exists without stable recurrence

## preserve-first rules

- candidate-only status를 유지할 수 있다
- thickening을 new line generation처럼 쓰지 않는다
- non-line 중심 사례는 non-line으로 남긴다
- promotion-ready wording을 피한다

## avoid

- explicit strong line wording without evidence
- stable family wording from one weak cue
- closure-by-line naming

## final sentence

Line/state organ은 line을 빨리 늘리는 기관이 아니라, line 가능성과 한계를 같이 표시하면서 과잉 생성과 조기 승격을 막는 기관이다.
