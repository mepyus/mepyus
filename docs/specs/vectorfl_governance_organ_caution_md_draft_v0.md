# Governance Organ CAUTION.md Draft v0

## caution purpose

Governance organ의 caution 규칙은  
current-reading이 읽힌다는 이유만으로 closure, promotion, direct action이 너무 빨리 열리는 것을 막는 데 목적이 있다.

## stop / hold conditions

- closure_before_presentation remains active
- observer_only should still hold
- promotion_forbidden should still hold
- release condition is not yet explicit

## preserve-first rules

- hold state를 숨기지 않는다
- restriction flags를 축소하지 않는다
- release condition과 next check trigger를 같이 남긴다
- trace-linked caution을 current-reading에서 끊지 않는다

## avoid

- generic approval wording
- safe-to-present wording without release condition
- removing caution for UI neatness

## final sentence

Governance organ은 막는 기관이기만 한 것이 아니라, premature closure를 막으면서 current-reading과 다음 handoff가 안전하게 유지되도록 caution을 분명히 드러내는 기관이다.
