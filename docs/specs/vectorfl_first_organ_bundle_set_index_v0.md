## 3. Reading Order

현재 기준에서 읽기 순서는 아래가 맞다.

`input`
-> `line/state`
-> `translation`
-> `flow interpretation`
-> `governance`
-> `trace/memory`

즉:

- input은 재료를 준비하고
- line/state는 형성 가능성과 carry를 읽고
- translation은 grammar를 만들고
- flow interpretation은 next hop을 읽고
- governance는 hold/restriction/current-reading-safe return을 만들고
- trace/memory는 residue/reentry continuity를 남긴다

## 4. What Is Still Missing

아직 아래는 붙지 않았다.

- additional organ bundle examples
- real file placement
- execution/runtime binding

즉 현재 세트는 first bundle의 중심 골격까지만 잠근 상태다.

현재 기준은 다음 문장으로 잠근다.

`VectorFL의 first organ bundle set은 input, line/state, translation, flow interpretation, governance, trace/memory 여섯 기관의 ROLE/HANDOFF/CAUTION/RETURN 초안으로 먼저 구성하고, 이후 추가 기관은 이 중심 골격 위에 확장하는 것이 맞다.`
