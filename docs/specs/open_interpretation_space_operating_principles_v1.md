# open interpretation space operating principles v1

## 1. purpose

- 이 문서의 목적은 앞으로 구조를 의미 잠금이 아니라 재해석 가능성 보존 쪽으로 운용하기 위한 원칙을 정리하는 것이다.

## 2. what must be fixed

- 원본 / 로그 / provenance를 바닥으로 유지하는 것
- 1차를 씨앗 흔적 보존층으로 보는 것
- 2차를 재순환/재독해층으로 보는 것
- hold를 deferred openness로 읽는 것
- failure를 future comparison memory로 남기는 것

## 3. what must not be fixed too early

- object naming을 본질 이름처럼 고정하는 일
- weak / fallback / partial 값을 폐기하는 일
- blocker를 영구 금지 목록처럼 읽는 일
- recent validation 자산을 단순 실패 리포트처럼 취급하는 일

## 4. temporary names vs essential names

- 임시 이름은 현재 계절의 읽힘을 돕는 표찰이다.
- 본질 이름은 여러 자산과 여러 계절을 지나도 남는 경우에만 천천히 논의할 수 있다.
- 따라서 지금 단계의 naming은 대부분 temporary surface로 보고, 기억과 조건을 함께 붙여 둔다.

## 5. residue and hold

- residue는 제거 대상이라기보다 읽힘을 흐리는 층의 기억이다.
- hold는 rejection이 아니라 나중에 다시 열어볼 수 있게 두는 자리 표시다.

## 6. record as memory

- 기록은 결과 보관이 아니라 계절 보관이다.
- recent report / note / gate / blocker 문서들은 현재 계절의 생육 기록이므로, 다음 계절의 재료가 들어오면 다시 읽혀야 한다.

## 7. failure as next-season material

- failure는 수정 압력만을 뜻하지 않는다.
- failure는:
  - 어디서 의미가 질식하는지
  - 어디서 carryover가 강한지
  - 어디서 열림이 아직 남아 있는지
  를 보여주는 다음 계절의 재료다.

## 8. one-line summary

> 열린 해석 공간의 구조는 의미를 닫기 위한 틀이 아니라, 흔적과 기억과 재해석 여지를 버티게 하는 바닥이며, hold와 failure와 weak/fallback 값은 모두 다음 계절을 위한 보존 자산으로 다뤄야 한다.
