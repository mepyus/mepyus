# Package Core v0

## Purpose

This spec defines the minimum meaning of package in this architecture.

## Definition

A package is the common meaning contract between external tools and our space.

It is not a UI object, not an agent workflow, and not an OMX runtime primitive.

## Role

A package gives received material a stable place in the space layer so it can be digested, reviewed, connected, and matured.

## Phase 1 Package Kinds

- intake: raw or lightly bounded material accepted into the space.
- digestion: worked material that extracts structure, claims, questions, or links.
- review: material prepared for checking, judgment, correction, or acceptance.
- memory: material promoted toward durable recall or reuse.

## Boundary

This version does not define a full JSON schema.

Fields, validation rules, IDs, storage formats, and lifecycle automation are left for later packages.
