# transcript preprocess comparison v0

## Purpose

이 note는 transcript-aware regroup 전/후를
같은 gate와 같은 probe 언어로 비교하는 점검면을 고정하기 위한 문서다.

## Reading rule

비교는 아래를 함께 본다.

- before gate / after gate
- before dust split / after dust split
- short shard pressure
- average chars per dust
- sample readability
- ingest readiness read

## Meaning

이 surface는 전처리기가 좋아 보인다는 인상을 만드는 용도가 아니다.
실제로 shard pressure가 줄었는지,
그리고 그래도 아직 direct ingest를 하면 안 되는지를 같이 읽기 위한 면이다.
