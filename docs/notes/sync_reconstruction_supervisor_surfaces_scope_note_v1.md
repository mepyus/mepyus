# sync_reconstruction_supervisor_surfaces_scope_note_v1

## purpose

- `scripts/sync_reconstruction_supervisor_surfaces.py`는 existing reconstruction packet 집합을 기준으로 navigation surface를 다시 맞추는 maintenance script다.

## in scope

- `reconstruction_supervisor_latest.md` 재생성
- `reconstruction_supervisor/index.json` 재생성
- `reconstruction_supervisor/index.md` 재생성
- `reconstruction_supervisor/folder_status.md` 재생성

## out of scope

- new reconstruction packet 생성
- receipt / views / sidecar 재선택
- decision logic
- governing behavior
- state mutation
