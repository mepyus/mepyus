 Dust Checklist v1

  이건 우리 엔진 앞단 입력 공정에서 dust를 승인하기 위한 1차 기준입니다.
  목표는 “잘게 자르기”가 아니라 “공간에 뿌릴 수 있는 입력 record 만들기”입니다.

  0. Dust 정의

  dust는 문장 단위가 아니다.
  dust는 하나의 지배적 의미 작용을 가지며, scene/flow를 안정적으로 붙일 수 있는 최소 맥락 단위다.

  1. 승인 조건

  아래를 모두 통과해야 dust로 승인한다.

  - 혼자 읽어도 이 조각이 무엇을 하는지 보인다.
  - 역할이 하나로 읽힌다.
  - scene을 붙일 수 있다.
  - flow를 붙일 수 있다.
  - 더 자르면 의미 힘이 약해진다.
  - 더 합치면 역할이 섞인다.

  2. 불승인 조건

  아래에 해당하면 독립 dust로 승인하지 않는다.

  - 짧은 동의
  - 짧은 정정
  - 짧은 사실 확인
  - 질문 한 줄만 있는 조각
  - 앞 문장을 보조하는 한 줄
  - 혼자 두면 scene/flow 설명이 약한 조각

  3. 강제 흡수 규칙

  아래는 앞뒤 dust에 흡수하는 것을 기본으로 한다.

  - 네, 맞아요, 그렇죠, 봤습니다 같은 짧은 응답
  - 날짜, 수치, 사실만 짧게 보정하는 발화
  - 앞 발화에 한 줄 덧붙이는 보조 설명
  - 질문 1줄 + 짧은 답 1줄
  - 단독으로 두면 의미 작용보다 반응 성격이 강한 조각

  4. 강제 제외 규칙

  아래는 dust가 아니라 marker metadata로 분리한다.

  - 챕터 제목
  - 편집 헤더
  - 링크 제목
  - 타임스탬프 라벨
  - 섹션 구분선
  - 이미지 캡션성 문구

  5. 너무 작은 dust 판정

  아래 중 하나면 너무 작을 가능성이 높다.

  - 접속이나 반응만 남는다.
  - 무엇에 대한 말인지 단독으로 안 보인다.
  - scene/flow는 붙일 수 있지만 설명력이 약하다.
  - 앞뒤와 합치면 훨씬 자연스럽다.

  6. 너무 큰 dust 판정

  아래 중 하나면 너무 클 가능성이 높다.

  - 사건 설명과 해석이 한 덩어리다.
  - 전환과 근거 제시가 동시에 있다.
  - 역할이 둘 이상 보인다.
  - scene 하나로 붙이기 어렵다.
  - flow 하나로 붙이기 어렵다.

  7. Scene 부여 규칙

  scene은 단어가 아니라 기능 기준으로 붙인다.

  - self: 자기감정, 자기평가, 내면 반응
  - work: 작업, 실행, 절차, 도구 사용
  - evidence: 사례, 사건, 관찰, 현장, 결과
  - meta: 해석, 비교, 관점, 역사화
  - unknown: 위 기준이 약할 때

  우선순위:

  - 사건/사례 중심이면 evidence
  - 해석/비교 중심이면 meta
  - 실제 작업 절차면 work
  - 내면 반응이면 self

  8. Flow 부여 규칙

  flow는 이 dust가 흐름에서 무엇을 하는지 본다.

  - contract: 줄임, 제한, 수축
  - expand: 설명 확장, 사례 전개, 논리 전개
  - bridge: 화제 연결, 전환, 매개
  - tension: 반박, 수정, 충돌, 긴장
  - unknown: 판정 약함

  빠른 기준:

  - 설명을 더 두껍게 하면 expand
  - 화제를 넘기면 bridge
  - 반대/수정하면 tension

  9. Time 규칙

  - 모든 dust는 t01, t02 같은 순서 앵커를 가진다.
  - 원문 timestamp가 있으면 함께 적는다.
  - time은 내용 의미가 아니라 입력 순서를 고정하는 값이다.

  10. 최소 출력 필드

  승인된 dust는 최소한 아래를 가져야 한다.

  [dust_01]
  source_range: ...
  text: ...
  unit_type: ...
  scene: ...
  flow: ...
  time: ...
  why_one_unit:
  - ...
  why_this_value:
  - ...
  merge_history:
  - ...
  confidence: ...

  초기 v1에서는 D/I/S보다 scene/flow 안정화가 우선이다.

  11. 운영 원칙

  - dust 수를 늘리는 것이 목표가 아니다.
  - 독립 의미 작용이 없는 조각은 과감히 흡수한다.
  - marker는 dust에 넣지 않는다.
  - 문장 경계보다 역할 경계를 우선한다.
  - 판정 이유를 반드시 남긴다.
