# Line Contracts Consolidated Draft v0

## 1. Definition of "Line"
라인(Line)은 단순한 문장, 데이터 덩어리(Chunk), 혹은 고정된 문서가 아니다. 
**"Raw(원시 데이터)와 Final(최종 결과) 사이에서 여러 단서, 관계, 공백, 압력을 묶어 다음 해석, 판단, 작업, 검증, 환류를 유발하는 지속 가능한 중간 운용 형성체"**로 정의한다.

## 2. Line as an Operating Unit
- 라인은 처음부터 고정된 객체가 아니라, 공간의 숙성에 따라 형태가 변하는 유기체다.
- 라인은 시스템(AI)과 사용자(인간)가 소통하는 핵심적인 '해석 가닥'이다.
- 라인은 단순한 티켓이나 위키 페이지가 아니며, 지속적으로 재독해(Reread)되어야 하는 렌즈 역할을 한다.

## 3. Core Principles
- **Read-First:** 라인을 형성하기 전에 먼저 읽어야 하며, 그 읽기 자체를 보호해야 한다.
- **Anti-Ontology:** 라인을 너무 빨리 고정된 온톨로지 객체로 확정하지 않는다. (Late Emergence 준수)
- **Traceability:** 모든 라인은 반드시 자신의 뿌리(Origin)와 형성 과정(Genealogy)을 증명할 수 있어야 한다.
