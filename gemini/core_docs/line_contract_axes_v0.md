# Line Contract Axes v0

## 1. The Four Axes of a Line
모든 라인은 아래 4가지 축을 기준으로 읽고 평가된다.

| Axis | Description |
| :--- | :--- |
| **Origin** | 이 라인이 어디서 왔는가? (소스 재료, 추출 스크립트, 대화 맥락 등) |
| **Meaning** | 어떤 의미 종류인가? (철학적 선언, 기술적 구조, 비즈니스 로직, 결핍 신호 등) |
| **Operating Role** | 지금 무엇을 위해 쓰이는가? (설계 가이드, 검증 기준, 구현 재료 등) |
| **Maturity** | 얼마나 숙성되었는가? (신뢰도, 단단함, 데이터 응결 정도) |

## 2. Temporal Stages (시간축)
라인의 생애주기에 따른 현재 단계이다.
- **Signal:** 미세한 징후 발견
- **Captured:** 단서 포착 및 기록
- **Forming:** 의미의 가닥 형성 중
- **Articulated:** 명확한 언어로 표현됨
- **Routed:** 특정 팀이나 담당에게 배정됨
- **Held:** 판단 보류 또는 간극 발견
- **Refluxed:** 사용자/공간으로 환류됨
- **Promoted:** 최종 자산이나 기준선으로 승격됨

## 3. Maturity Levels (숙성축)
라인이 가진 정보의 밀도와 단단함의 정도이다.
- **Weak:** 얇고 불확실한 연결
- **Emerging:** 서서히 드러나는 맥락
- **Usable:** 작업 재료로 사용 가능한 수준
- **Strong:** 단단한 근거와 관계를 가진 상태
- **Promotion Ready:** 승격 직전의 완결된 라인
